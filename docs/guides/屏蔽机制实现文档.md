## 1. 功能概述

### 1.1 核心功能

ProjectU 的屏蔽机制提供了灵活的内容过滤能力，支持4种屏蔽维度：

| 屏蔽类型 | 说明 | 规则特性 |
|---------|------|---------|
| **R-18 作品** | 基于年龄限制（`AgeLimit`）过滤 | 固定规则，可启用/禁用 |
| **AI 生成作品** | 基于 `isAiGenerated` 标识过滤 | 固定规则，可启用/禁用 |
| **作者ID** | 屏蔽指定作者的所有作品 | 动态规则，可添加/删除 |
| **标签** | 屏蔽包含特定标签的作品 | 动态规则，可添加/删除 |

### 1.2 设计原则

- **响应式**: 规则变更立即生效，基于 Kotlin Flow 实现
- **高性能**: 使用 BlockRuleCache 内存缓存，零数据库查询
- **集中式过滤**: 在 Repository 层统一过滤，减少重复代码
- **持久化存储**: 使用 Room 数据库存储屏蔽规则
- **Clean Architecture**: 遵循现有项目架构模式

#### D. 过滤器

**ContentFilter**
```kotlin
class ContentFilter {
    fun filterArtworks(artworks: List<Artwork>, rules: List<BlockRule>): List<Artwork> {
        return artworks.filter { artwork ->
            !shouldBlock(artwork, rules)
        }
    }
    
    private fun shouldBlock(artwork: Artwork, rules: List<BlockRule>): Boolean {
        for (rule in rules) {
            when (rule.type) {
                R18_CONTENT -> 
                    if (artwork.ageLimit == AgeLimit.R18 || 
                        artwork.ageLimit == AgeLimit.R18G) return true
                        
                AI_GENERATED -> 
                    if (artwork.isAiGenerated) return true
                    
                AUTHOR_ID -> 
                    if (artwork.userId == rule.value) return true
                    
                TAG -> 
                    if (artwork.tags.any { 
                        it.name == rule.value || 
                        it.translatedName == rule.value 
                    }) return true
            }
        }
        return false
    }
}
```

**FilterArtworksUseCase**
```kotlin
class FilterArtworksUseCase(
    private val blockRuleCache: BlockRuleCache,
    private val contentFilter: ContentFilter
) {
    operator fun invoke(artworks: List<Artwork>): List<Artwork> {
        // 从内存缓存读取，不查询数据库
        val enabledRules = blockRuleCache.getEnabledRules()
        
        // 快速路径：无规则时直接返回
        if (enabledRules.isEmpty()) return artworks
        
        return contentFilter.filterArtworks(artworks, enabledRules)
    }
}
```

## 4. 性能优化（已实现）

### BlockRuleCache 内存缓存

**解决问题**: 消除每次列表请求都查询数据库的性能瓶颈

**设计方案**: 参考 `SettingsCache` 设计模式，创建 `BlockRuleCache` 内存缓存

**实现代码**:

1. **创建 BlockRuleCache**
```kotlin
// 位置: shared/src/commonMain/kotlin/com/projectu/shared/domain/cache/BlockRuleCache.kt

/**
 * 屏蔽规则缓存
 * 用于高频访问场景，避免重复查询数据库
 * 参考 SettingsCache 设计
 */
class BlockRuleCache(
    private val blockRuleRepository: BlockRuleRepository
) {
    private val scope = CoroutineScope(Dispatchers.Default + SupervisorJob())
    
    // 内存缓存：启用的规则
    private val _enabledRules = MutableStateFlow<List<BlockRule>>(emptyList())
    val enabledRules: StateFlow<List<BlockRule>> = _enabledRules.asStateFlow()
    
    init {
        // 订阅数据库变化，自动同步到内存
        scope.launch {
            blockRuleRepository.observeEnabledRules().collect { rules ->
                _enabledRules.value = rules
            }
        }
    }
    
    /**
     * 同步获取启用的规则（内存访问，零延迟）
     */
    fun getEnabledRules(): List<BlockRule> = _enabledRules.value
    
    /**
     * 检查是否有启用的规则
     */
    fun hasEnabledRules(): Boolean = _enabledRules.value.isNotEmpty()
}
```

2. **更新 FilterArtworksUseCase**
```kotlin
class FilterArtworksUseCase(
    private val blockRuleCache: BlockRuleCache,  // ← 使用缓存而不是 Repository
    private val contentFilter: ContentFilter
) {
    operator fun invoke(artworks: List<Artwork>): List<Artwork> {
        // 从内存缓存读取，不再查询数据库
        val rules = blockRuleCache.getEnabledRules()
        
        // 快速路径：没有启用的规则时直接返回
        if (rules.isEmpty()) return artworks
        
        return contentFilter.filterArtworks(artworks, rules)
    }
}
```

3. **配置依赖注入**
```kotlin
// shared/src/commonMain/kotlin/com/projectu/shared/di/SharedModule.kt

val cacheModule = module {
    // 单例缓存
    single { BlockRuleCache(get()) }
}

val useCaseModule = module {
    factory { 
        FilterArtworksUseCase(
            blockRuleCache = get(),  // ← 注入缓存
            contentFilter = get()
        ) 
    }
}
```

| 响应时间 | ~50-100ms | <1ms |

## 6. 使用指南

### 6.1 用户操作流程

#### 启用 R-18 屏蔽
1. 进入 **设置** → **屏蔽列表**
2. 在"固定屏蔽规则"区域找到"R-18 作品"
3. 打开开关
4. 返回主界面，所有 R-18 作品将被过滤

#### 屏蔽特定作者
1. 进入 **设置** → **屏蔽列表**
2. 点击右下角"+"按钮
3. 选择"作者ID"
4. 输入作者ID（例如：`12345678`）
5. 输入显示名称（例如：作者昵称）
6. 点击"添加"
7. 该作者的所有作品将被过滤

#### 屏蔽特定标签
1. 进入 **设置** → **屏蔽列表**
2. 点击右下角"+"按钮
3. 选择"标签"
4. 输入标签名称（例如：`初音ミク`）
5. 点击"添加"
6. 包含该标签的所有作品将被过滤
