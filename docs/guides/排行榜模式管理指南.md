# 排行榜模式管理指南

> 📅 创建日期: 2025-11-26  
> 🎯 目标: 管理 Pixiv 排行榜的复杂 content 和 mode 关系

---

## 📊 问题背景

Pixiv 排行榜系统有两个维度：
1. **Content 维度**（内容类型）: all, illust, manga, ugoira, novel
2. **Mode 维度**（排行榜模式）: daily, weekly, monthly, rookie, 等

**复杂性**：不同的 content 类型支持不同的 mode，需要一个清晰的方式来管理这些关系。

---

## 🏗️ 架构设计

### 核心组件

| 组件 | 路径 | 功能 |
|-----|------|------|
| **RankingContent** | `shared/data/remote/model/RankingContent.kt` | 内容类型枚举 |
| **RankingMode** | `shared/data/remote/model/RankingMode.kt` | 排行榜模式枚举 |
| **RankingContentModeConfig** | `shared/data/remote/model/RankingContentModeConfig.kt` | 兼容性配置管理器 |

### 设计思路

```
┌─────────────────────────────────────────┐
│         RankingContent (5种)            │
│  ALL, ILLUST, MANGA, UGOIRA, NOVEL     │
└──────────────┬──────────────────────────┘
               │ 支持关系
               ↓
┌─────────────────────────────────────────┐
│    RankingContentModeConfig (配置)      │
│  • 管理 content 和 mode 的兼容性       │
│  • 提供查询和过滤方法                  │
└──────────────┬──────────────────────────┘
               │ 映射到
               ↓
┌─────────────────────────────────────────┐
│         RankingMode (18种)              │
│  daily, weekly, monthly, rookie...     │
│  + 小说专属: weekly_original, ...       │
└─────────────────────────────────────────┘
```

## 📝 RankingContent（内容类型）

### 枚举定义

```kotlin
enum class RankingContent(
    val value: String,
    val displayName: String
) {
    ALL("all", "全部"),
    ILLUST("illust", "插画"),
    MANGA("manga", "漫画"),
    UGOIRA("ugoira", "动图"),
    NOVEL("novel", "小说")
}
```

### 使用方法

```kotlin
// 从字符串创建
val content = RankingContent.fromValue("illust")

// 获取支持的 modes
val modes = RankingContent.getSupportedModes(RankingContent.ILLUST)
// 返回: [DAILY, WEEKLY, MONTHLY, ROOKIE, DAILY_R18, WEEKLY_R18, R18G]
```

## 🎭 RankingMode（排行榜模式）

### 分类体系

RankingMode 有两个维度：
1. **RankingCategory**（内容分类）: GENERAL（一般）, R18, R18G
2. **RankingAiType**（AI类型）: NON_AI（普通）, AI

### 所有模式列表

| 模式 | value | 分类 | AI类型 | 适用 content |
|-----|-------|------|--------|--------------|
| DAILY | daily | GENERAL | NON_AI | all, illust, manga, ugoira, novel |
| WEEKLY | weekly | GENERAL | NON_AI | all, illust, manga, ugoira, novel |
| MONTHLY | monthly | GENERAL | NON_AI | all, illust, manga, novel |
| ROOKIE | rookie | GENERAL | NON_AI | all, illust, manga, novel |
| ORIGINAL | original | GENERAL | NON_AI | all |
| MALE | male | GENERAL | NON_AI | all, novel |
| FEMALE | female | GENERAL | NON_AI | all, novel |
| DAILY_AI | daily_ai | GENERAL | AI | all |
| **WEEKLY_ORIGINAL** | weekly_original | GENERAL | NON_AI | all, **novel** 🆕 |
| **WEEKLY_AI** | weekly_ai | GENERAL | AI | all, **novel** 🆕 |
| DAILY_R18 | daily_r18 | R18 | NON_AI | all, illust, manga, ugoira, novel |
| WEEKLY_R18 | weekly_r18 | R18 | NON_AI | all, illust, manga, ugoira, novel |
| MALE_R18 | male_r18 | R18 | NON_AI | all, novel |
| FEMALE_R18 | female_r18 | R18 | NON_AI | all, novel |
| DAILY_R18_AI | daily_r18_ai | R18 | AI | all |
| **WEEKLY_R18_AI** | weekly_r18_ai | R18 | AI | all, **novel** 🆕 |
| R18G | r18g | R18G | NON_AI | all, illust, manga, novel |

**注**: 标注 🆕 的是新增的小说专属模式

### 使用方法

```kotlin
// 获取一般向排行榜
val generalModes = RankingMode.getGeneralModes()

// 获取 R-18 排行榜
val r18Modes = RankingMode.getR18Modes()

// 根据分类和AI类型过滤
val generalNonAi = RankingMode.getModes(
    category = RankingCategory.GENERAL,
    aiType = RankingAiType.NON_AI
)

// 获取小说专属模式
val novelExclusive = RankingMode.getNovelExclusiveModes()
// 返回: [WEEKLY_ORIGINAL, WEEKLY_AI, WEEKLY_R18_AI]
```

## ⚙️ RankingContentModeConfig（配置管理器）

### 兼容性映射

| Content | 支持的 Modes |
|---------|------------|
| **ALL** | 15 种 mode（**不包括**小说专属的 3 种） |
| **ILLUST** | daily, weekly, monthly, rookie, daily_r18, weekly_r18, r18g (7种) |
| **MANGA** | daily, weekly, monthly, rookie, daily_r18, weekly_r18, r18g (7种) |
| **UGOIRA** | daily, weekly, daily_r18, weekly_r18 (4种) |
| **NOVEL** | daily, weekly, monthly, rookie, male, female, daily_r18, weekly_r18, male_r18, female_r18, r18g, **weekly_original**, **weekly_ai**, **weekly_r18_ai** (14种) |

### 核心方法

#### 1. 获取支持的 modes

```kotlin
// 获取插画支持的所有 modes
val illustModes = RankingContentModeConfig.getSupportedModes(RankingContent.ILLUST)
// 返回: [DAILY, WEEKLY, MONTHLY, ROOKIE, DAILY_R18, WEEKLY_R18, R18G]

// 获取小说支持的所有 modes
val novelModes = RankingContentModeConfig.getSupportedModes(RankingContent.NOVEL)
// 返回: 14 种 mode（包含小说专属的 3 种）
```

#### 2. 检查兼容性

```kotlin
// 检查 ILLUST 是否支持 WEEKLY_ORIGINAL
val isCompatible = RankingContentModeConfig.isCompatible(
    RankingContent.ILLUST,
    RankingMode.WEEKLY_ORIGINAL
)
// 返回: false（WEEKLY_ORIGINAL 只有小说支持）

// 检查 NOVEL 是否支持 WEEKLY_ORIGINAL
val isCompatible2 = RankingContentModeConfig.isCompatible(
    RankingContent.NOVEL,
    RankingMode.WEEKLY_ORIGINAL
)
// 返回: true
```

#### 3. 反向查询：获取支持某个 mode 的 contents

```kotlin
// 获取支持 WEEKLY_ORIGINAL 的所有 content
val contents = RankingContentModeConfig.getSupportedContents(RankingMode.WEEKLY_ORIGINAL)
// 返回: [ALL, NOVEL]
```

#### 4. 获取默认 mode

```kotlin
// 获取插画的默认 mode
val defaultMode = RankingContentModeConfig.getDefaultMode(RankingContent.ILLUST)
// 返回: DAILY（优先级: daily > weekly > monthly > 其他）
```

#### 5. 按条件过滤 modes

```kotlin
// 获取插画的一般向排行榜
val illustGeneral = RankingContentModeConfig.getFilteredModes(
    content = RankingContent.ILLUST,
    category = RankingCategory.GENERAL,
    aiType = null
)
// 返回: [DAILY, WEEKLY, MONTHLY, ROOKIE]

// 获取小说的 R-18 AI 排行榜
val novelR18Ai = RankingContentModeConfig.getFilteredModes(
    content = RankingContent.NOVEL,
    category = RankingCategory.R18,
    aiType = RankingAiType.AI
)
// 返回: [WEEKLY_R18_AI]
```

#### 6. 便捷方法

```kotlin
// 获取插画的一般向排行榜
val generalModes = RankingContentModeConfig.getGeneralModes(RankingContent.ILLUST)

// 获取小说的 R-18 排行榜
val r18Modes = RankingContentModeConfig.getR18Modes(RankingContent.NOVEL)

// 获取动图的非 AI 排行榜
val nonAiModes = RankingContentModeConfig.getNonAiModes(RankingContent.UGOIRA)

// 获取所有小说专属模式
val novelExclusive = RankingContentModeConfig.getNovelExclusiveModes()

// 检查是否为小说专属模式
val isNovelExclusive = RankingContentModeConfig.isNovelExclusiveMode(RankingMode.WEEKLY_AI)
// 返回: true
```

## 🎨 UI 使用示例

### 场景 1: 两级选择（推荐）

**流程**: 先选择 Content，再根据 Content 动态显示可用的 Mode

```kotlin
@Composable
fun RankingScreen() {
    var selectedContent by remember { mutableStateOf(RankingContent.ALL) }
    var selectedMode by remember { mutableStateOf(RankingMode.DAILY) }
    
    // 获取当前 content 支持的 modes
    val availableModes = remember(selectedContent) {
        RankingContentModeConfig.getSupportedModes(selectedContent)
    }
    
    // 当 content 变化时，自动调整 mode
    LaunchedEffect(selectedContent) {
        if (!availableModes.contains(selectedMode)) {
            // 如果当前 mode 不支持，切换到默认 mode
            selectedMode = RankingContentModeConfig.getDefaultMode(selectedContent) 
                ?: availableModes.firstOrNull() 
                ?: RankingMode.DAILY
        }
    }
    
    Column {
        // 第一级：Content 选择
        ContentSelector(
            selected = selectedContent,
            onSelect = { selectedContent = it }
        )
        
        // 第二级：Mode 选择（动态过滤）
        ModeSelector(
            availableModes = availableModes,
            selected = selectedMode,
            onSelect = { selectedMode = it }
        )
        
        // 显示排行榜内容
        RankingContent(content = selectedContent, mode = selectedMode)
    }
}

@Composable
fun ContentSelector(
    selected: RankingContent,
    onSelect: (RankingContent) -> Unit
) {
    Row(
        horizontalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        RankingContent.entries.forEach { content ->
            FilterChip(
                selected = selected == content,
                onClick = { onSelect(content) },
                label = { Text(content.displayName) }
            )
        }
    }
}

@Composable
fun ModeSelector(
    availableModes: List<RankingMode>,
    selected: RankingMode,
    onSelect: (RankingMode) -> Unit
) {
    LazyRow(
        horizontalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        items(availableModes) { mode ->
            FilterChip(
                selected = selected == mode,
                onClick = { onSelect(mode) },
                label = { Text(mode.displayName) },
                // 小说专属模式可以加特殊标记
                leadingIcon = if (RankingContentModeConfig.isNovelExclusiveMode(mode)) {
                    { Icon(Icons.Default.Book, contentDescription = "小说专属") }
                } else null
            )
        }
    }
}
```

### 场景 2: 分组选择

**流程**: 按分类（一般/R-18/R-18G）分组显示

```kotlin
@Composable
fun RankingScreenGrouped() {
    var selectedContent by remember { mutableStateOf(RankingContent.ALL) }
    var selectedCategory by remember { mutableStateOf(RankingCategory.GENERAL) }
    var selectedMode by remember { mutableStateOf(RankingMode.DAILY) }
    
    Column {
        // Content 选择
        ContentSelector(selectedContent) { selectedContent = it }
        
        // Category 选择
        CategorySelector(selectedCategory) { selectedCategory = it }
        
        // 获取过滤后的 modes
        val filteredModes = remember(selectedContent, selectedCategory) {
            RankingContentModeConfig.getFilteredModes(
                content = selectedContent,
                category = selectedCategory,
                aiType = null
            )
        }
        
        // Mode 选择
        if (filteredModes.isNotEmpty()) {
            ModeSelector(filteredModes, selectedMode) { selectedMode = it }
        } else {
            Text("该组合无可用排行榜", color = MaterialTheme.colorScheme.error)
        }
    }
}
```

### 场景 3: 带验证的 API 调用

```kotlin
class RankingViewModel : ViewModel() {
    fun loadRanking(content: RankingContent, mode: RankingMode) {
        // 验证兼容性
        if (!RankingContentModeConfig.isCompatible(content, mode)) {
            _state.update { 
                it.copy(error = "不支持的组合: ${content.displayName} + ${mode.displayName}") 
            }
            return
        }
        
        // 调用 API
        viewModelScope.launch {
            rankingApi.getRanking(
                mode = mode.value,
                content = content.value
            ).onSuccess { data ->
                _state.update { it.copy(rankings = data) }
            }
        }
    }
}
```

## 🎯 最佳实践

### 1. 总是验证兼容性

```kotlin
// ✅ 推荐：调用 API 前验证
if (RankingContentModeConfig.isCompatible(content, mode)) {
    api.getRanking(content, mode)
} else {
    showError("不支持的组合")
}

// ❌ 不推荐：直接调用可能失败
api.getRanking(content, mode)
```

### 2. 使用默认值

```kotlin
// ✅ 推荐：使用配置管理器的默认值
val defaultMode = RankingContentModeConfig.getDefaultMode(content) ?: RankingMode.DAILY

// ❌ 不推荐：硬编码默认值
val defaultMode = RankingMode.DAILY  // 可能不支持当前 content
```

### 3. 动态更新可用选项

```kotlin
// ✅ 推荐：content 变化时动态更新 mode 列表
LaunchedEffect(selectedContent) {
    availableModes = RankingContentModeConfig.getSupportedModes(selectedContent)
    if (!availableModes.contains(selectedMode)) {
        selectedMode = availableModes.firstOrNull() ?: RankingMode.DAILY
    }
}

// ❌ 不推荐：使用静态的 mode 列表
val availableModes = RankingMode.entries  // 包含不支持的选项
```

### 4. 提供用户友好的提示

```kotlin
// 小说专属模式的特殊标记
if (RankingContentModeConfig.isNovelExclusiveMode(mode)) {
    Text("此排行榜仅小说可用", style = MaterialTheme.typography.bodySmall)
}

// 不兼容时的提示
if (!RankingContentModeConfig.isCompatible(content, mode)) {
    Text("${content.displayName}不支持${mode.displayName}排行榜")
}
```
