## 一、功能需求

### 1. 支持的资源类型
1. **插画** (Illustration) - 单图作品
2. **漫画** (Manga) - 多图作品
3. **动图** (Ugoira) - Pixiv动图
4. **小说** (Novel) - 文字作品
5. **小说系列** (Novel Series) - 多章节小说

### 2. 路径管理
- **基础路径**: 用户可选择总文件夹
- **分类路径**: 各资源类型默认相对路径，可单独设置
- **R-18分离**: 支持将R-18作品保存到单独文件夹
- **AI作品分离**: 支持将AI作品保存到单独文件夹
- **作者文件夹**: 3个选项（不启用、作者ID、作者名）

### 3. 文件命名
支持自定义模板，可用变量：
- `{id}` - 作品ID
- `{p}` - P数（页码）
- `{title}` - 作品标题
- `{author_id}` - 作者ID
- `{author_name}` - 作者名
- `{publish_date}` - 发布时间
- `{download_date}` - 下载时间
- `{ai}` - AI标识
- `{r18}` - R-18标识
- `{tags}` - 标签（多个用_连接）

### 4. 特殊格式处理
- **Ugoira**: 优先保存为GIF，后期支持MP4导出
- **小说**: 优先TXT，支持下载内嵌图片并生成EPUB/HTML
- **小说系列**: 下载所有章节并合并为单个文件

### 5. 下载策略
- 使用最清晰版本（Original质量）
- 优先从缓存获取（节省带宽）
- 支持断点续传（未来）

### 6. 下载管理
- 下载列表展示所有任务
- 支持单任务操作：开始、暂停、删除
- 显示下载进度和状态

### 7. 系统兼容性
- 文件路径合法性检查（跨平台）
- 文件名非法字符处理
- 路径长度限制（Windows 260字符）

### 8. 下载状态查询
- 在作品详情页显示是否已下载
- 影响UI元素（下载按钮图标变化）

### 1. 文件系统跨平台支持 ✅

**实际实现**:
```kotlin
// Android 10+ 使用 MediaStore API
class AndroidFileWriter(private val context: Context) : PlatformFileWriter {
    override fun createSink(path: Path, displayName: String): Sink {
        return if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
            createMediaStoreSink(path, displayName)
        } else {
            createLegacySink(path)
        }
    }
    
    private fun createMediaStoreSink(path: Path, displayName: String): Sink {
        val resolver = context.contentResolver
        val mimeType = getMimeType(displayName)
        val collection = getCollection(mimeType)
        
        // 使用 IS_PENDING 标志实现原子写入
        val contentValues = ContentValues().apply {
            put(MediaStore.MediaColumns.DISPLAY_NAME, displayName)
            put(MediaStore.MediaColumns.MIME_TYPE, mimeType)
            put(MediaStore.MediaColumns.RELATIVE_PATH, getRelativePath(path))
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
                put(MediaStore.MediaColumns.IS_PENDING, 1)
            }
        }
        
        val uri = resolver.insert(collection, contentValues)
        return resolver.openOutputStream(uri!!).sink().buffer()
    }
}
```

### 2. 下载进度追踪 ✅

**实际实现**:
```kotlin
private suspend fun downloadFileWithProgress(
    url: String,
    fullPath: Path,
    fileName: String,
    taskId: String
) {
    httpClient.prepareGet(url) {
        header(HttpHeaders.Referer, "https://www.pixiv.net/")
    }.execute { response ->
        val channel = response.bodyAsChannel()
        val contentLength = response.contentLength() ?: -1L
        var downloadedBytes = 0L
        
        // 使用 PlatformFileWriter 创建平台特定的 Sink
        platformFileWriter.createSink(fullPath, fileName).use { sink ->
            while (!channel.isClosedForRead) {
                val packet = channel.readRemaining(DEFAULT_BUFFER_SIZE.toLong())
                while (packet.isNotEmpty) {
                    val bytes = packet.readByteArray()
                    sink.write(bytes)
                    downloadedBytes += bytes.size
                    
                    // 实时更新进度到数据库
                    val progress = if (contentLength > 0) {
                        downloadedBytes.toFloat() / contentLength
                    } else 0f
                    
                    downloadDao.updateTaskStatus(
                        taskId = taskId,
                        status = DownloadStatus.DOWNLOADING.name,
                        progress = progress,
                        downloadedSize = downloadedBytes
                    )
                }
            }
        }
        
        // Android 10+: 清除 IS_PENDING 标志
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
            clearPendingFlag(uri)
        }
    }
}
```

### 4. 文件名合法性处理 ✅

**实际实现**:
```kotlin
private fun sanitizeFileName(name: String): String {
    // Windows非法字符: \ / : * ? " < > |
    // macOS/Linux非法字符: /
    val illegalChars = Regex("""[\\/:*?"<>|]""")
    return name
        .replace(illegalChars, "_")  // 替换非法字符
        .replace("\r\n", " ")         // 替换换行符
        .replace("\n", " ")
        .trim()
        .take(200)                    // 限制长度（避免Windows 260字符路径限制）
        .ifEmpty { "untitled" }       // 空文件名兜底
}
```

## 八、Android存储策略 ✅ **新增**

### 版本适配方案

| Android版本 | API Level | 存储API | 权限要求 | 实现方式 |
|------------|-----------|---------|----------|----------|
| 7-9 (Nougat-Pie) | 24-28 | File API | WRITE_EXTERNAL_STORAGE | AndroidFileWriter.createLegacySink() |
| 10-12 (Q-S) | 29-32 | MediaStore | 无需权限 | AndroidFileWriter.createMediaStoreSink() |
| 13+ (Tiramisu+) | 33+ | MediaStore | READ_MEDIA_IMAGES/VIDEO | AndroidFileWriter.createMediaStoreSink() |

### AndroidManifest权限声明

```xml
<!-- Android 7-9: 传统存储权限 -->
<uses-permission 
    android:name="android.permission.WRITE_EXTERNAL_STORAGE"
    android:maxSdkVersion="28" />

<!-- Android 7-12: 读取外部存储 -->
<uses-permission 
    android:name="android.permission.READ_EXTERNAL_STORAGE"
    android:maxSdkVersion="32" />

<!-- Android 13+: 媒体权限 -->
<uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
<uses-permission android:name="android.permission.READ_MEDIA_VIDEO" />

<!-- Android 10兼容模式（可选） -->
<application
    android:requestLegacyExternalStorage="true">
```

### MediaStore实现要点

1. **IS_PENDING标志**: 原子文件创建，避免未完成文件被扫描
2. **MIME类型检测**: 自动路由到正确的Collection（Images/Video/Downloads）
3. **RELATIVE_PATH**: 使用相对路径，兼容Scoped Storage
4. **重复文件处理**: 删除旧MediaStore记录，避免EEXIST错误
