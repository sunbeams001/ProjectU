## 🔄 后续需要完成的任务

### 1. 登录过期拦截器 ⏳

**目标**: 自动检测 API 返回的 401/403 错误，跳转到登录页面

**实现位置**: `shared/data/remote/api/PixivApiClient.kt`

**建议方案**:
```kotlin
// 在 PixivApiClient 中添加响应拦截
suspend inline fun <reified T> get(...): PixivResponse<T> {
    return try {
        val response = httpClient.get(...).body<PixivResponse<T>>()
        
        // 检查是否需要重新登录
        if (response.error == true && response.message?.contains("login") == true) {
            throw UnauthorizedException("登录已过期")
        }
        
        response
    } catch (e: ClientRequestException) {
        when (e.response.status.value) {
            401, 403 -> throw UnauthorizedException("登录已过期")
            else -> throw e
        }
    }
}

// 在 App.kt 中全局捕获
LaunchedEffect(Unit) {
    // 监听未授权异常
    // 跳转到登录页面
}
```

**注意**: 需要先通过调试确认 Pixiv API 在凭据过期时的实际响应格式！

## 🎯 使用指南

### 用户使用流程

1. **首次启动应用**
   - 自动显示登录界面
   - 点击右上角"?"查看帮助

2. **获取 PHPSESSID**
   - 浏览器登录 https://www.pixiv.net/
   - F12 打开开发者工具
   - Application → Cookies → 复制 PHPSESSID

3. **输入凭据并登录**
   - 粘贴 PHPSESSID（格式: `12345678_xxxxxxxxxxxx`）
   - 点击"登录"按钮
   - 成功后自动跳转到主页

4. **后续使用**
   - 凭据自动持久化
   - 下次启动直接进入主页
   - 凭据过期时会提示重新登录

### 开发者调试

```kotlin
// 检查登录状态
val authRepository: AuthRepository = get()
val isLoggedIn = authRepository.isLoggedIn()
println("已登录: $isLoggedIn")

// 获取当前配置
val config = authRepository.getPixivConfig()
println("PHPSESSID: ${config.phpSessionId}")
println("用户ID: ${config.getUserId()}")

// 手动清除凭据
authRepository.clearCredentials()
```
