# 存储权限与文件管理方案

## 项目配置

- **minSdk**: 24 (Android 7.0)
- **targetSdk**: 36 (Android 16/V)
- **compileSdk**: 36

## 存储策略

### Android 版本分层处理

#### 1. Android 7-9 (API 24-28)
**策略**: 传统外部存储
- **权限**: `WRITE_EXTERNAL_STORAGE` (运行时权限)
- **API**: `java.io.File` 直接访问
- **路径**: `/storage/emulated/0/Pictures/ProjectU/...`
- **特点**: 需要用户授予存储权限

#### 2. Android 10-12 (API 29-32)
**策略**: MediaStore API (分区存储)
- **权限**: 无需特殊权限
- **API**: `MediaStore.Images.Media`, `MediaStore.Video.Media`
- **路径**: 通过 `RELATIVE_PATH` 指定 (`Pictures/ProjectU/...`)
- **特点**: 
  - 自动处理权限
  - 使用 `IS_PENDING` 标记保证原子性
  - 文件对其他应用立即可见

#### 3. Android 13+ (API 33+)
**策略**: MediaStore API + 精细化权限
- **权限**: `READ_MEDIA_IMAGES`, `READ_MEDIA_VIDEO` (读取已有文件)
- **API**: MediaStore API
- **特点**: 写入无需权限，读取需要媒体权限

## 实现细节

### AndroidFileWriter.kt

```kotlin
class AndroidFileWriter(private val context: Context) : PlatformFileWriter {
    
    // 根据 Android 版本选择策略
    override suspend fun createSink(path: Path, displayName: String): Sink {
        return when {
            Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q -> 
                createMediaStoreSink(path, displayName)  // Android 10+
            else -> 
                createLegacySink(path)                    // Android 7-9
        }
    }
}
```

### 关键特性

1. **自动版本适配**: 根据运行时 Android 版本自动选择正确的 API
2. **权限最小化**: 
   - Android 10+ 写入无需权限
   - Android 7-9 仅请求必要的 WRITE_EXTERNAL_STORAGE
3. **文件可见性**: 
   - MediaStore 使用 IS_PENDING 确保写入完整性
   - 写入完成后自动对系统相册可见
4. **错误处理**: 
   - EEXIST: 通过删除检测避免
   - EPERM: 通过 MediaStore API 避免

## AndroidManifest.xml 权限声明

```xml
<!-- Android 7-9: 写入外部存储 -->
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE"
    android:maxSdkVersion="28" />

<!-- Android 10-12: 读取外部存储 -->
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE"
    android:maxSdkVersion="32" />

<!-- Android 13+: 精细化媒体权限 -->
<uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
<uses-permission android:name="android.permission.READ_MEDIA_VIDEO" />

<!-- Android 10 兼容模式（可选，用于测试） -->
<application android:requestLegacyExternalStorage="true">
```

## StoragePermissionManager 使用

### 在 Activity 中

```kotlin
class MainActivity : ComponentActivity() {
    private val permissionManager by lazy { StoragePermissionManager(this) }
    
    fun downloadFile() {
        if (permissionManager.hasStoragePermission()) {
            // 执行下载
            startDownload()
        } else {
            permissionManager.requestStoragePermission { granted ->
                if (granted) startDownload()
                else showPermissionDeniedDialog()
            }
        }
    }
}
```

### 在 Composable 中

```kotlin
@Composable
fun DownloadButton() {
    val permissionManager = rememberStoragePermissionManager()
    
    Button(onClick = {
        permissionManager.requestStoragePermission { granted ->
            if (granted) {
                // 执行下载
            }
        }
    }) {
        Text("下载")
    }
}
```

## 常见问题

### Q: Android 10 为什么不需要存储权限？
A: 从 Android 10 开始，使用 MediaStore API 写入公共媒体目录（Pictures、Movies、Downloads）无需权限。

### Q: requestLegacyExternalStorage 的作用？
A: 在 Android 10 设备上临时启用旧的存储模式，仅用于测试兼容性。Android 11+ 忽略此标志。

### Q: 为什么删除文件会失败？
A: 
- Android 10+: 应用只能删除自己创建的文件
- 其他应用创建的文件需要用户通过系统 UI 确认

### Q: 如何在系统相册中查看下载的文件？
A: MediaStore 会自动扫描，文件在 IS_PENDING=0 后立即可见于相册应用。
