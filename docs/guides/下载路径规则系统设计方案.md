# 下载路径规则系统设计方案

## 1. 设计目标

### 1.1 核心问题
原有的固定路径配置方案存在以下问题：
- **配置繁琐**：需要为每种资源类型（插画/漫画/动图/小说）分别配置 R-18 路径、AI 路径，总计需要配置 10+ 个路径
- **多条件冲突**：当作品同时满足多个条件（如"R-18 + AI"）时，无法明确应该使用哪个路径
- **灵活性不足**：无法实现复杂的分类需求（如"R-18 AI 作品按作者分类，普通作品统一存储"）
- **扩展困难**：未来添加新的分类维度（如标签、收藏数）需要大量修改

### 1.2 新方案目标
- ✅ **极简默认**：零配置即可使用，按资源类型存储到默认路径
- ✅ **灵活规则**：支持多条自定义规则，覆盖各种分类需求
- ✅ **优先级清晰**：从上到下匹配，使用第一个匹配的规则
- ✅ **高性能**：利用缓存机制，避免高频数据库查询
- ✅ **易扩展**：规则系统可轻松添加新的匹配维度

### 1.3 核心设计理念

**路径管理权交给用户**：

在新规则系统中，当用户创建一条规则并指定了 `resourceTypeFilter`（如"仅匹配插画"），实际上用户已经通过规则的 `basePath` 隐式地决定了资源的分类方式。因此，系统不再自动添加资源类型文件夹。

**示例对比**：

❌ **旧逻辑（自动添加资源类型文件夹）**：
```
用户规则：[插画, R-18, basePath="/NSFW"]
实际路径：/NSFW/Illustrations/xxx.jpg  ← 系统自动添加 Illustrations
```

✅ **新逻辑（用户完全控制）**：
```
用户规则：[插画, R-18, basePath="/NSFW"]
实际路径：/NSFW/xxx.jpg  ← 用户通过 basePath 决定路径

如果用户想区分类型，可以这样配置：
规则1：[插画, R-18, basePath="/NSFW/Illustrations"]
规则2：[漫画, R-18, basePath="/NSFW/Manga"]
```

**优势**：
- 🎯 **简洁性**：用户选择的路径就是最终存储位置，所见即所得
- 🎯 **灵活性**：用户可以自由决定是否需要资源类型分类
- 🎯 **混合存储**：支持将多种资源类型存储在同一目录（如"所有 R-18 作品不分类型"）

### 2.2 数据流向

**写入流程（用户修改规则）**：
```
UI (拖拽排序/添加规则)
  ↓
ViewModel.moveRule() / addRule()
  ↓
Repository.updateRuleOrder() / upsertRule()
  ↓
Store (Room Database 写入)
  ↓
Cache (自动通过 Flow 订阅更新)
```

**读取流程（下载任务执行）**：
```
DownloadManager.createTask()
  ↓
DownloadRulesCache.findMatchingRule(task) // 内存查询，O(n)
  ↓
返回匹配的规则 (或 null 表示使用默认规则)
  ↓
根据规则构建路径: basePath/{author?}
```

### 3.3 领域模型

```kotlin
/**
 * 下载规则（领域模型）
 */
data class DownloadRule(
    val id: Long = 0,
    val order: Int,
    val resourceTypeFilter: ResourceTypeFilter,
    val r18Filter: FilterType,
    val aiFilter: FilterType,
    val authorGrouping: AuthorGrouping,
    val targetPath: String,
    val enabled: Boolean = true,
    val createdAt: Long = System.currentTimeMillis(),
    val updatedAt: Long = System.currentTimeMillis()
) {
    /**
     * 判断给定的下载任务是否匹配此规则
     * 
     * @param task 下载任务
     * @return true 表示匹配，false 表示不匹配
     */
    fun matches(task: DownloadTask): Boolean {
        // 1. 资源类型匹配
        if (resourceTypeFilter != ResourceTypeFilter.ANY) {
            val expectedType = when (resourceTypeFilter) {
                ResourceTypeFilter.ILLUSTRATION -> ResourceType.ILLUSTRATION
                ResourceTypeFilter.MANGA -> ResourceType.MANGA
                ResourceTypeFilter.UGOIRA -> ResourceType.UGOIRA
                ResourceTypeFilter.NOVEL -> ResourceType.NOVEL
                ResourceTypeFilter.NOVEL_SERIES -> ResourceType.NOVEL_SERIES
                ResourceTypeFilter.ANY -> null // 不会进入这个分支
            }
            if (task.resourceType != expectedType) return false
        }
        
        // 2. R-18 匹配
        when (r18Filter) {
            FilterType.MUST_BE -> if (!task.isR18) return false
            FilterType.MUST_NOT_BE -> if (task.isR18) return false
            FilterType.ANY -> { /* 不过滤 */ }
        }
        
        // 3. AI 匹配
        when (aiFilter) {
            FilterType.MUST_BE -> if (!task.isAi) return false
            FilterType.MUST_NOT_BE -> if (task.isAi) return false
            FilterType.ANY -> { /* 不过滤 */ }
        }
        
        return true
    }
    
    /**
     * 根据规则和任务信息构建相对路径
     * 
     * @param task 下载任务
     * @return 相对路径，例如："123456" 或 "ArtistName"，如果不分组则返回空字符串
     * 
     * 注意：不再自动添加资源类型文件夹，用户通过规则的 basePath 自行管理
     */
    fun buildRelativePath(task: DownloadTask): String {
        // 根据作者分组模式构建路径
        return when (authorGrouping) {
            AuthorGrouping.BY_ID -> task.authorId
            AuthorGrouping.BY_NAME -> sanitizeFileName(task.authorName)
            AuthorGrouping.NONE -> "" // 不创建子文件夹
        }
    }
    
    /**
     * 文件名合法化处理
     */
    private fun sanitizeFileName(name: String): String {
        val illegalChars = Regex("""[\\/:*?"<>|\u0000-\u001F\u007F]""")
        return name
            .replace(illegalChars, "_")
            .trim()
            .take(200)
            .ifEmpty { "Unknown" }
    }
}
```

```kotlin
        downloadRulesDao.upsertRule(rule)
    }
    
    /**
     * 删除规则
     */
    suspend fun deleteRule(ruleId: Long) {
        downloadRulesDao.deleteRuleById(ruleId)
    }
    
    /**
     * 批量更新规则顺序（用于拖拽排序）
     */
    suspend fun updateRulesOrder(rules: List<DownloadRuleEntity>) {
        val updatedRules = rules.mapIndexed { index, rule ->
            rule.copy(
                ruleOrder = index,
                updatedAt = System.currentTimeMillis()
            )
        }
        downloadRulesDao.upsertRules(updatedRules)
    }
    
    /**
     * 启用/禁用规则
     */
    suspend fun setRuleEnabled(ruleId: Long, enabled: Boolean) {
        downloadRulesDao.setRuleEnabled(ruleId, enabled)
    }
    
    /**
     * 获取规则数量
     */
    suspend fun getRuleCount(): Int {
        return downloadRulesDao.getRuleCount()
    }
```

## 5. 缓存层设计 ⭐

### 5.1 DownloadRulesCache

```kotlin
/**
 * 下载规则缓存
 * 
 * 设计目标：
 * - 避免每次下载任务都查询数据库
 * - 提供同步的规则匹配方法
 * - 自动订阅 Store 更新，保持缓存一致性
 * 
 * 性能优化：
 * - 规则列表存储在内存中（StateFlow）
 * - findMatchingRule() 时间复杂度：O(n)，n 为规则数量
 * - 规则数量限制：建议最多 20 条，实际匹配耗时 < 1ms
 */
class DownloadRulesCache(
    private val downloadRulesStore: DownloadRulesStore
) {
    private val coroutineScope = CoroutineScope(Dispatchers.Default + SupervisorJob())
    
    /**
     * 缓存的规则列表（按优先级排序）
     */
    private val _rules = MutableStateFlow<List<DownloadRule>>(emptyList())
    val rules: StateFlow<List<DownloadRule>> = _rules.asStateFlow()
    
    init {
        // 自动订阅数据库更新
        coroutineScope.launch {
            downloadRulesStore.rules.collect { entities ->
                _rules.value = entities.map { it.toDownloadRule() }
            }
        }
    }
    
    /**
     * 查找匹配的规则（同步方法，用于下载任务）
     * 
     * @param task 下载任务
     * @return 第一个匹配的规则，如果没有匹配则从内置默认规则组中查找
     */
    fun findMatchingRule(task: DownloadTask): DownloadRule {
        val enabledRules = _rules.value.filter { it.enabled }
        
        // 1. 遍历用户自定义规则，返回第一个匹配的规则
        for (rule in enabledRules) {
            if (rule.matches(task)) {
                return rule
            }
        }
        
        // 2. 没有自定义规则匹配，使用内置默认规则组
        val builtInRules = DownloadRuleDefaults.getBuiltInRules()
        for (rule in builtInRules) {
            if (rule.matches(task)) {
                return rule
            }
        }
        
        // 3. 理论上不应该到这里（内置规则应该覆盖所有类型）
        throw IllegalStateException("No matching rule found for task: ${task.resourceType}")
    }
    
    /**
     * 获取当前规则数量
     */
    fun getRuleCount(): Int = _rules.value.size
    
    /**
     * 判断是否有自定义规则
     */
    fun hasCustomRules(): Boolean = _rules.value.isNotEmpty()
    
    /**
     * 清理资源
     */
    fun clear() {
        coroutineScope.cancel()
    }
}
```

### 5.2 缓存性能分析

**场景 1：下载 100 个作品**

不使用缓存 ❌：
```kotlin
for (task in tasks) {
    // 每次都查询数据库
    val rules = repository.getRules().first() // 100 次数据库查询
    val matchedRule = rules.firstOrNull { it.matches(task) }
}
// 总耗时：100 * 5ms = 500ms（假设每次查询 5ms）
```

使用缓存 ✅：
```kotlin
for (task in tasks) {
    // 内存查询
    val matchedRule = rulesCache.findMatchingRule(task) // O(n)，n = 规则数量
}
```

```kotlin
fun buildRuleDescription(rule: DownloadRule): String {
    val parts = mutableListOf<String>()
    
    // 资源类型
    if (rule.resourceTypeFilter != ResourceTypeFilter.ANY) {
        val typeName = when (rule.resourceTypeFilter) {
            ResourceTypeFilter.ILLUSTRATION -> "插画"
            ResourceTypeFilter.MANGA -> "漫画"
            ResourceTypeFilter.UGOIRA -> "动图"
            ResourceTypeFilter.NOVEL -> "小说"
            ResourceTypeFilter.NOVEL_SERIES -> "小说系列"
            ResourceTypeFilter.ANY -> ""
        }
        parts.add(typeName)
    }
    
    // R-18
    when (rule.r18Filter) {
        FilterType.MUST_BE -> parts.add("R-18")
        FilterType.MUST_NOT_BE -> parts.add("非R-18")
        FilterType.ANY -> {}
    }
    
    // AI
    when (rule.aiFilter) {
        FilterType.MUST_BE -> parts.add("AI作品")
        FilterType.MUST_NOT_BE -> parts.add("非AI作品")
        FilterType.ANY -> {}
    }
    
    // 作者分组
    val grouping = when (rule.authorGrouping) {
        AuthorGrouping.BY_ID -> "，按作者ID分组"
        AuthorGrouping.BY_NAME -> "，按作者名分组"
        AuthorGrouping.NONE -> ""
    }
    
    val prefix = if (parts.isEmpty()) "所有作品" else parts.joinToString(" + ")
    return "$prefix$grouping"
}
```

```kotlin
        settingsStore: SettingsStore,
        rulesStore: DownloadRulesStore
    ): Boolean {
        val ruleCount = rulesStore.getRuleCount()

                resourceType = ResourceTypeFilter.ILLUSTRATION,
                r18Filter = FilterType.MUST_BE,
                path = settings.r18IllustPath
            ))
        }
        
        // ... 迁移其他旧配置
        
        // 批量插入规则
        if (rules.isNotEmpty()) {

        }
    }
```

```kotlin
/**
 * 规则验证器
 */
object DownloadRuleValidator {
    /**
     * 验证规则有效性
     */
    fun validate(rule: DownloadRule): Result<Unit> {
        // 1. 路径不能为空
        if (rule.targetPath.isBlank()) {
            return Result.failure(Exception("目标路径不能为空"))
        }
        
        // 2. 路径长度限制
        if (rule.targetPath.length > 500) {
            return Result.failure(Exception("路径过长（最大 500 字符）"))
        }
        
        // 3. SAF URI 格式验证
        if (rule.targetPath.startsWith("content://")) {
            try {
                Uri.parse(rule.targetPath)
            } catch (e: Exception) {
                return Result.failure(Exception("无效的 URI 格式"))
            }
        }
        
        return Result.success(Unit)
    }
    
    /**
     * 检测规则冲突（提示用户）
     */
    fun detectConflicts(rules: List<DownloadRule>): List<RuleConflict> {
        val conflicts = mutableListOf<RuleConflict>()
        
        // 检测永远不会被触发的规则
        for (i in rules.indices) {
            for (j in 0 until i) {
                if (rules[j].shadows(rules[i])) {
                    conflicts.add(
                        RuleConflict(
                            shadowedRule = rules[i],
                            shadowingRule = rules[j],
                            message = "规则 ${i+1} 被规则 ${j+1} 覆盖，永远不会被触发"
                        )
                    )
                }
            }
        }
        
        return conflicts
    }
}
```

```kotlin
        val cache = DownloadRulesCache(downloadRulesStore)
        
        // 初始状态
        assertEquals(0, cache.getRuleCount())
        
        // 添加规则
        downloadRulesStore.upsertRule(createTestRule())
        
        // 等待缓存更新
        advanceUntilIdle()
        
        // 验证缓存已更新
        assertEquals(1, cache.getRuleCount())
    }
}
```
