# 刷新机制设计指南

本文档总结了排行榜页面的多种刷新方式设计，可作为其他页面实现刷新功能的参考。

## 设计理念

提供多种刷新触发方式，满足不同用户的使用习惯，提升用户体验：
- **手势操作**：符合移动端用户习惯
- **点击操作**：提供明确的刷新入口
- **智能判断**：根据列表位置决定行为（滚动或刷新）

## 四种刷新方式

### 1. 下拉刷新（Pull to Refresh）

**适用场景**：列表类页面的标准刷新方式

**实现方式**：
```kotlin
import androidx.compose.material3.pulltorefresh.PullToRefreshBox

@Composable
fun YourListLayout(
    items: List<YourItem>,
    isRefreshing: Boolean,
    onRefresh: () -> Unit,
    listState: LazyListState = rememberLazyListState()
) {
    PullToRefreshBox(
        isRefreshing = isRefreshing,
        onRefresh = onRefresh,
        modifier = Modifier.fillMaxSize()
    ) {
        LazyColumn(
            state = listState,
            modifier = Modifier.fillMaxSize()
        ) {
            items(items) { item ->
                // Item 内容
            }
        }
    }
}
```

**注意事项**：
- `isRefreshing` 应该是 `state.isLoading && 数据不为空`，避免初次加载时显示刷新指示器
- 支持 Compose Multiplatform（Android + Desktop）
- 自动处理手势识别和动画效果

### 2. 点击已选中的 Tab/Mode

**适用场景**：多 Tab 页面或有模式切换的页面

**设计逻辑**：
- **列表在顶部** → 刷新数据
- **列表不在顶部** → 平滑滚动到顶部（再次点击则刷新）

**实现方式**：

```kotlin
// 1. 创建滚动状态检查函数
val scrollToTopOrRefresh: () -> Unit = {
    val listState = getCurrentListState() // 获取当前列表状态
    val isAtTop = when (listState) {
        is LazyStaggeredGridState -> 
            listState.firstVisibleItemIndex == 0 && 
            listState.firstVisibleItemScrollOffset == 0
        is LazyListState -> 
            listState.firstVisibleItemIndex == 0 && 
            listState.firstVisibleItemScrollOffset == 0
        else -> true
    }
    
    if (isAtTop) {
        onRefresh()
    } else {
        coroutineScope.launch {
            listState.animateScrollToItem(0)
        }
    }
}

// 2. Tab/Mode 选择器中使用
FilterChip(
    selected = isSelected,
    onClick = {
        if (isSelected) {
            scrollToTopOrRefresh()
        } else {
            onModeChange(mode)
        }
    },
    label = { Text(mode.displayName) }
)
```

**用户体验优势**：
- 避免误触导致的刷新
- 给用户快速返回顶部的方式
- 符合 iOS 和 Android 的交互习惯

### 3. 重复点击底部导航 Tab

**适用场景**：底部导航或侧边导航的页面

**实现方式**：

```kotlin
// 1. 在 Tab 对象中定义触发器
object YourTab : Tab {
    private val _scrollToTopOrRefreshTrigger = mutableStateOf(0L)
    val scrollToTopOrRefreshTrigger: State<Long> = _scrollToTopOrRefreshTrigger
    
    fun triggerScrollToTopOrRefresh() {
        _scrollToTopOrRefreshTrigger.value = System.currentTimeMillis()
    }
    
    @Composable
    override fun Content() {
        val scrollToTopOrRefreshCallback = remember { mutableStateOf<(() -> Unit)?>(null) }
        
        LaunchedEffect(scrollToTopOrRefreshTrigger.value) {
            if (scrollToTopOrRefreshTrigger.value > 0) {
                scrollToTopOrRefreshCallback.value?.invoke()
            }
        }
        
        YourPageContent(
            onRegisterScrollToTopOrRefreshCallback = { callback ->
                scrollToTopOrRefreshCallback.value = callback
            }
        )
    }
}

// 2. 导航栏中检测重复点击
NavigationBarItem(
    selected = tabNavigator.current == tab,
    onClick = {
        if (tabNavigator.current == tab && tab == YourTab) {
            YourTab.triggerScrollToTopOrRefresh()
        } else {
            tabNavigator.current = tab
        }
    },
    icon = { Icon(...) },
    label = { Text(...) }
)

// 3. 页面内容注册回调
@Composable
fun YourPageContent(
    onRegisterScrollToTopOrRefreshCallback: ((() -> Unit) -> Unit)? = null
) {
    val scrollToTopOrRefresh: () -> Unit = {
        // 检查列表位置，决定刷新或滚动
    }
    
    LaunchedEffect(scrollToTopOrRefresh) {
        onRegisterScrollToTopOrRefreshCallback?.invoke(scrollToTopOrRefresh)
    }
}
```

**优势**：
- 提供全局快速刷新入口
- 无需额外 UI 元素
- 符合用户直觉

### 4. 错误重试按钮

**适用场景**：所有需要网络请求的页面

**实现方式**：

```kotlin
when {
    state.error != null && items.isEmpty() -> {
        Column(
            modifier = Modifier.align(Alignment.Center),
            horizontalAlignment = Alignment.CenterHorizontally,
            verticalArrangement = Arrangement.spacedBy(8.dp)
        ) {
            Text(
                text = state.error,
                color = MaterialTheme.colorScheme.error
            )
            Button(onClick = onRefresh) {
                Text("重试")
            }
        }
    }
}
```

**注意事项**：
- 只在列表为空且有错误时显示
- 如果列表已有数据，错误可以用 Snackbar 提示

## 完整示例：排行榜页面

### 架构设计

```
RankingTab (导航 Tab)
    ↓ 触发器传递
RankingContent (内容容器)
    ↓ 回调注册
    ├─ RankingModeSelector (Mode 选择器)
    └─ HorizontalPager
        └─ ArtworkStaggeredGridLayout / NovelListLayout
            └─ PullToRefreshBox (下拉刷新容器)
                └─ LazyColumn / LazyVerticalStaggeredGrid
```

### 核心代码结构

```kotlin
// 1. Tab 层 - 处理重复点击触发
object RankingTab : Tab {
    private val _scrollToTopOrRefreshTrigger = mutableStateOf(0L)
    
    fun triggerScrollToTopOrRefresh() {
        _scrollToTopOrRefreshTrigger.value = System.currentTimeMillis()
    }
    
    @Composable
    override fun Content() {
        val scrollToTopOrRefreshCallback = remember { mutableStateOf<(() -> Unit)?>(null) }
        
        LaunchedEffect(scrollToTopOrRefreshTrigger.value) {
            if (scrollToTopOrRefreshTrigger.value > 0) {
                scrollToTopOrRefreshCallback.value?.invoke()
            }
        }
        
        RankingContent(
            state = state,
            onRefresh = viewModel::refresh,
            onRegisterScrollToTopOrRefreshCallback = { callback ->
                scrollToTopOrRefreshCallback.value = callback
            }
        )
    }
}

// 2. Content 层 - 管理滚动状态和回调
@Composable
fun RankingContent(
    state: RankingState,
    onRefresh: () -> Unit,
    onRegisterScrollToTopOrRefreshCallback: ((() -> Unit) -> Unit)? = null
) {
    val listStates = remember(state.currentContentType) {
        mutableStateMapOf<String, Any>()
    }
    val coroutineScope = rememberCoroutineScope()
    
    val scrollToTopOrRefresh: () -> Unit = {
        val currentMode = state.currentMode
        val listState = listStates[currentMode.value]
        val isAtTop = when (listState) {
            is LazyStaggeredGridState -> 
                listState.firstVisibleItemIndex == 0 && 
                listState.firstVisibleItemScrollOffset == 0
            is LazyListState -> 
                listState.firstVisibleItemIndex == 0 && 
                listState.firstVisibleItemScrollOffset == 0
            else -> true
        }
        
        if (isAtTop) {
            onRefresh()
        } else {
            coroutineScope.launch {
                when (listState) {
                    is LazyStaggeredGridState -> listState.animateScrollToItem(0)
                    is LazyListState -> listState.animateScrollToItem(0)
                }
            }
        }
    }
    
    LaunchedEffect(scrollToTopOrRefresh) {
        onRegisterScrollToTopOrRefreshCallback?.invoke(scrollToTopOrRefresh)
    }
    
    RankingModeSelector(
        onRefreshOrScrollToTop = scrollToTopOrRefresh
    )
    
    // HorizontalPager with list content...
}

// 3. List 层 - 实现下拉刷新
@Composable
fun ArtworkStaggeredGridLayout(
    artworks: List<Artwork>,
    onRefresh: () -> Unit,
    isRefreshing: Boolean,
    listState: LazyStaggeredGridState
) {
    PullToRefreshBox(
        isRefreshing = isRefreshing,
        onRefresh = onRefresh,
        modifier = Modifier.fillMaxSize()
    ) {
        LazyVerticalStaggeredGrid(
            state = listState,
            modifier = Modifier.fillMaxSize()
        ) {
            items(artworks) { artwork ->
                ArtworkCard(artwork)
            }
        }
    }
}
```

## 状态管理最佳实践

### 1. 区分加载状态

```kotlin
data class YourState(
    val isLoading: Boolean = false,      // 初次加载或刷新
    val isLoadingMore: Boolean = false,  // 加载更多（分页）
    val error: String? = null,
    val items: List<Item> = emptyList()
)

// 下拉刷新状态判断
val isRefreshing = state.isLoading && state.items.isNotEmpty()
```

### 2. 滚动状态管理

对于多 Tab/Mode 页面，每个 Tab/Mode 应该维护独立的滚动状态：

```kotlin
// 为每个 mode 创建独立的列表状态缓存
val listStates = remember(contentType) {
    mutableStateMapOf<String, Any>()
}

// 为当前 mode 获取或创建列表状态
val listState = rememberLazyListState()
remember(modeKey) {
    listStates.getOrPut(modeKey) { listState }
}
```

### 3. 刷新逻辑

```kotlin
fun refresh() {
    viewModelScope.launch {
        _state.update { it.copy(isLoading = true, error = null) }
        try {
            val data = repository.fetchData()
            _state.update { it.copy(
                items = data,
                isLoading = false
            )}
        } catch (e: Exception) {
            _state.update { it.copy(
                isLoading = false,
                error = e.message
            )}
        }
    }
}
```

## 设计决策参考

### 何时使用智能滚动（滚动到顶部 vs 刷新）

**推荐使用**：
- 列表内容较长的页面
- 用户可能深入滚动浏览的页面
- 多 Tab/Mode 切换的页面

**不推荐使用**：
- 列表内容较短的页面
- 主要交互不是滚动的页面
- 实时更新的页面（如聊天）

### 刷新方式组合建议

| 页面类型 | 推荐刷新方式 | 说明 |
|---------|-------------|------|
| 单列表页面 | 下拉刷新 + 错误重试 | 最简单的组合 |
| 多 Tab 列表 | 下拉刷新 + 点击 Tab + 错误重试 | 标准组合 |
| 带筛选的列表 | 下拉刷新 + 点击筛选项 + 错误重试 | 适合排行榜类 |
| 主页/首页 | 所有四种 | 提供最完整的体验 |

## 技术要点

### PullToRefreshBox 使用注意

1. **Compose Multiplatform 支持**：需要 Compose Multiplatform 1.9.0+
2. **导入路径**：`androidx.compose.material3.pulltorefresh.PullToRefreshBox`
3. **嵌套滚动**：PullToRefreshBox 会自动处理嵌套滚动冲突
4. **自定义指示器**：可通过 `indicator` 参数自定义刷新指示器

### 滚动状态判断

```kotlin
// LazyColumn/LazyRow
val isAtTop = listState.firstVisibleItemIndex == 0 && 
              listState.firstVisibleItemScrollOffset == 0

// LazyVerticalStaggeredGrid/LazyHorizontalStaggeredGrid
val isAtTop = staggeredGridState.firstVisibleItemIndex == 0 && 
              staggeredGridState.firstVisibleItemScrollOffset == 0
```

### 协程作用域

使用 `rememberCoroutineScope()` 在 Composable 中启动协程：

```kotlin
val coroutineScope = rememberCoroutineScope()

Button(onClick = {
    coroutineScope.launch {
        listState.animateScrollToItem(0)
    }
}) {
    Text("回到顶部")
}
```

## 可访问性建议

1. **语义化标签**：为刷新操作提供清晰的内容描述
2. **触觉反馈**：刷新开始时提供振动反馈（移动端）
3. **视觉反馈**：确保刷新状态有明显的视觉指示
4. **键盘支持**：Desktop 平台支持 F5 或 Ctrl+R 刷新（可选）

## 总结

多种刷新方式的设计原则：
1. **用户优先**：提供多种触发方式，满足不同用户习惯
2. **智能判断**：根据上下文决定最合适的行为
3. **清晰反馈**：每种刷新方式都有明确的视觉反馈
4. **性能优化**：避免不必要的刷新，保持状态一致性
5. **跨平台支持**：确保在 Android 和 Desktop 平台都能正常工作
