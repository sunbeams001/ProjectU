## 1. 功能概述

### 1.1 设计目标

ProjectU 备份与恢复功能旨在为用户提供完整的数据保护和迁移能力，支持：

- ✅ **可选择性备份**: 用户可以选择备份哪些数据类型
- ✅ **版本兼容**: 支持不同版本之间的备份文件恢复
- ✅ **数据完整性**: 确保备份数据的一致性和完整性
- ✅ **跨平台支持**: Android 和 Desktop 平台通用
- ✅ **隐私保护**: 敏感信息加密存储

### 1.2 核心特性

| 特性 | 说明 |
|-----|------|
| **模块化备份** | 用户可选择性备份不同数据模块 |
| **增量备份** | 支持仅备份变更数据（可选） |
| **压缩存储** | 使用 ZIP 格式压缩备份文件 |
| **版本管理** | 记录数据库版本，支持向后兼容 |
| **数据校验** | SHA-256 校验和验证数据完整性 |
| **加密保护** | 敏感信息（登录凭据）使用 AES-256 加密 |

## 2. 备份内容定义

### 2.1 备份模块分类

根据用户需求和数据特点，将备份内容分为以下模块：

| 模块ID | 模块名称 | 数据来源 | 优先级 | 大小估算 |
|-------|---------|---------|--------|---------|
| `SETTINGS` | 应用设置 | SettingsEntity | P0 (已实现) | < 10KB |
| `CREDENTIALS` | 登录信息 | PixivConfigStore (DataStore) | P0 (已实现) | < 5KB |
| `BLOCK_RULES` | 屏蔽列表 | BlockRuleEntity | P1 | < 50KB |
| `BROWSE_HISTORY` | 浏览历史 | BrowseHistoryEntity | P1 | 100KB - 10MB |
| `DOWNLOAD_RULES` | 下载路径规则 | DownloadRuleEntity | P1 | < 20KB |
| `FILE_NAMING` | 文件命名规则 | SettingsEntity | P1 | < 5KB |
| `DOWNLOAD_TASKS` | 下载任务记录 | DownloadTaskEntity | P2 | 100KB - 50MB |
| `SEARCH_HISTORY` | 搜索历史 | SearchHistoryStore (DataStore) | P2 | < 100KB |

### 2.2 各模块详细说明

#### A. 应用设置 (SETTINGS)

**数据来源**: `app_settings` 表 (SettingsEntity)

**包含内容**:
```kotlin
- appLanguage: String                    // 应用界面语言
- pixivLanguage: String                  // Pixiv API 语言
- themeMode: String                      // 主题模式
- r18SanityLevelThreshold: Int           // R18 阈值
- preferredImageQuality: String          // 图片质量偏好
- detailImageQuality: String             // 详情页图片质量
- viewerImageQuality: String             // 大图浏览质量
- novelDownloadImageQuality: String      // 小说下载图片质量
- imageCacheSize: String                 // 图片缓存大小
- clickBookmarkAction: String            // 点击收藏行为
- longPressBookmarkAction: String        // 长按收藏行为
- waterfallColumns: Int                  // 瀑布流列数
- enableBlurNSFW: Boolean                // NSFW 模糊
- showTranslatedTagsFirst: Boolean       // 优先显示翻译标签
- autoPlayUgoira: Boolean                // 自动播放动图
- fileNameTemplate: String               // 文件命名模板
- fileNameMode: String                   // 文件命名模式
```

**备份大小**: < 10KB  
**是否必选**: 是（默认选中）

---

#### B. 登录信息 (CREDENTIALS)

**数据来源**: `PixivConfigStore` (DataStore Preferences)

**包含内容**:
```kotlin
- phpSessionId: String                   // PHPSESSID Cookie（加密）
- csrfToken: String?                     // CSRF Token（加密）
```

**备份大小**: < 5KB  
**是否必选**: 否（默认选中，但用户可取消）  
**安全措施**: 
- 明确警告用户备份文件包含登录凭据
- *注：P0阶段由于技术限制暂时明文存储，计划在P2阶段引入AES-256加密*

---

#### C. 屏蔽列表 (BLOCK_RULES)

**数据来源**: `block_rules` 表 (BlockRuleEntity)

**包含内容**:
```kotlin
- id: String                             // 唯一ID
- type: String                           // 屏蔽类型: R18_CONTENT, AI_GENERATED, AUTHOR_ID, TAG
- value: String                          // 屏蔽值（作者ID/标签名）
- displayName: String                    // 显示名称
- matchMode: String                      // 匹配模式（标签）
- enabled: Boolean                       // 是否启用
- scopes: String                         // 作用范围
- createdAt: Long                        // 创建时间
- updatedAt: Long                        // 更新时间
```

**备份大小**: < 50KB（假设 < 500 条规则）  
**是否必选**: 否（默认选中）

---

#### D. 浏览历史 (BROWSE_HISTORY)

**数据来源**: `browse_history` 表 (BrowseHistoryEntity)

**包含内容**:
```kotlin
- id: String                             // {type}_{contentId}
- contentType: String                    // ILLUST, MANGA, UGOIRA, NOVEL, NOVEL_SERIES, MANGA_SERIES
- contentId: String                      // 作品ID
- title: String                          // 标题
- thumbnailUrl: String?                  // 缩略图URL
- authorId: String?                      // 作者ID
- authorName: String?                    // 作者名称
- isR18: Boolean                         // R18标识
- isAi: Boolean                          // AI标识
- viewedAt: Long                         // 浏览时间
- createdAt: Long                        // 创建时间
```

**备份大小**: 100KB - 10MB（取决于历史记录数量）  
**是否必选**: 否（默认选中）  
**备份策略**:
- 可选择备份时间范围（如最近 30 天、90 天、全部）
- 可选择最大记录数（如最近 1000 条、5000 条、全部）

---

#### E. 下载路径规则 (DOWNLOAD_RULES)

**数据来源**: `download_rules` 表 (DownloadRuleEntity)

**包含内容**:
```kotlin
- id: Long                               // 唯一ID
- ruleOrder: Int                         // 规则优先级
- resourceTypes: String                  // 资源类型集合（JSON）
- r18Filter: String                      // R-18 过滤器
- aiFilter: String                       // AI 作品过滤器
- authorGrouping: String                 // 作者分组模式
- targetPath: String                     // 目标路径
- subDirectory: String                   // 子目录
- enabled: Boolean                       // 是否启用
- createdAt: Long                        // 创建时间
- updatedAt: Long                        // 更新时间
```

**备份大小**: < 20KB  
**是否必选**: 否（默认选中）  
**注意事项**:
- 路径可能包含平台特定格式（如 Android SAF URI）
- 恢复时需要提示用户验证路径有效性

---

#### F. 文件命名规则 (FILE_NAMING)

**数据来源**: `app_settings` 表中的命名相关字段

**包含内容**:
```kotlin
- fileNameMode: String                   // STANDARD, CUSTOM
- fileNameTemplate: String               // 自定义模板字符串
```

**备份大小**: < 5KB  
**是否必选**: 否（默认选中，与 SETTINGS 模块合并）

---

#### G. 下载任务记录 (DOWNLOAD_TASKS)

**数据来源**: `download_tasks` 表 (DownloadTaskEntity)

**包含内容**:
```kotlin
- id: String                             // 唯一ID
- resourceType: String                   // 资源类型
- resourceId: String                     // 资源ID
- title: String                          // 标题
- authorId: String                       // 作者ID
- authorName: String                     // 作者名称
- pageIndex: Int?                        // 页码
- totalPages: Int                        // 总页数
- isR18: Boolean                         // R18标识
- isAi: Boolean                          // AI标识
- tags: String                           // 标签（JSON）
- thumbnailUrl: String?                  // 缩略图URL
- publishTime: Long                      // 发布时间
- downloadTime: Long                     // 下载时间
- status: String                         // 状态
- progress: Float                        // 进度
- targetPath: String                     // 目标路径
- fileName: String                       // 文件名
- fileSize: Long                         // 文件大小
- downloadedSize: Long                   // 已下载大小
- error: String?                         // 错误信息
- createdAt: Long                        // 创建时间
- updatedAt: Long                        // 更新时间
```

**备份大小**: 100KB - 50MB（取决于任务数量）  
**是否必选**: 否（默认不选中）  
**备份策略**:
- 仅备份已完成的任务记录
- 不包含实际下载的文件，仅记录元数据
- 可选择备份时间范围

---

#### H. 搜索历史 (SEARCH_HISTORY)

**数据来源**: `SearchHistoryStore` (DataStore Preferences)

**包含内容**:
```kotlin
- searchHistory: List<String>            // 搜索关键词列表
```

**备份大小**: < 100KB  
**是否必选**: 否（默认选中）  
**备注**: 搜索历史包含置顶状态（`isPinned`）和置顶时间（`pinnedTimestamp`），可完整恢复用户的置顶设置

## 4. 数据模型设计

### 4.1 备份文件结构

备份文件使用 **ZIP** 格式，包含以下内容：

```
backup_20250121_143025.pbu  (ProjectU Backup File)
├── metadata.json                    # 备份元数据
├── settings.json                    # 应用设置
├── credentials.enc                  # 登录信息（AES加密）
├── block_rules.json                 # 屏蔽列表
├── browse_history.json              # 浏览历史
├── download_rules.json              # 下载路径规则
├── download_tasks.json              # 下载任务记录
├── search_history.json              # 搜索历史（含置顶状态）
└── checksums.json                   # 各文件校验和
```

```kotlin
fun encryptCredentials(
    credentials: CredentialsData,
    password: String
): EncryptedData {
    // 1. 生成随机盐值
    val salt = SecureRandom().generateBytes(32)
    
    // 2. 使用 PBKDF2 派生密钥
    val key = PBKDF2.deriveKey(
        password = password,
        salt = salt,
        iterations = 100000,
        keyLength = 256
    )
    
    // 3. AES-256-GCM 加密
    val cipher = Cipher.getInstance("AES/GCM/NoPadding")
    cipher.init(Cipher.ENCRYPT_MODE, key)
    val iv = cipher.iv
    val plaintext = json.encodeToString(credentials)
    val ciphertext = cipher.doFinal(plaintext.toByteArray())
    
    // 4. 返回加密数据
    return EncryptedData(
        algorithm = "AES-256-GCM",
        salt = salt.toBase64(),
        iv = iv.toBase64(),
        ciphertext = ciphertext.toBase64()
    )
}
```

```kotlin
fun calculateChecksum(data: ByteArray): String {
    val digest = MessageDigest.getInstance("SHA-256")
    val hash = digest.digest(data)
    return hash.toHexString()
}

// 计算整体校验和
fun calculateOverallChecksum(checksums: Map<String, String>): String {
    val combined = checksums.entries
        .sortedBy { it.key }
        .joinToString("") { it.value }
    return calculateChecksum(combined.toByteArray())
}
```

```kotlin
fun mergeBrowseHistory(
    current: List<BrowseHistoryEntity>,
    backup: List<BrowseHistoryEntity>
): List<BrowseHistoryEntity> {
    val merged = mutableMapOf<String, BrowseHistoryEntity>()
    
    // 1. 添加当前数据
    current.forEach { merged[it.id] = it }
    
    // 2. 合并备份数据
    backup.forEach { backupItem ->
        val existingItem = merged[backupItem.id]
        if (existingItem == null) {
            // 备份中有，当前没有：直接添加
            merged[backupItem.id] = backupItem
        } else {
            // 两者都有：保留最新的
            if (backupItem.viewedAt > existingItem.viewedAt) {
                merged[backupItem.id] = backupItem
            }
        }
    }
    
    return merged.values.toList()
}
```

```kotlin
fun decryptCredentials(
    encryptedData: EncryptedData,
    password: String
): CredentialsData {
    // 1. 使用相同参数派生密钥
    val key = PBKDF2.deriveKey(
        password = password,
        salt = encryptedData.salt.fromBase64(),
        iterations = encryptedData.iterations,
        keyLength = 256

    // 2. AES-256-GCM 解密
    val cipher = Cipher.getInstance("AES/GCM/NoPadding")
    cipher.init(

        GCMParameterSpec(128, encryptedData.iv.fromBase64())
    )

        val plaintext = cipher.doFinal(encryptedData.ciphertext.fromBase64())
        val jsonString = plaintext.decodeToString()
        return json.decodeFromString(jsonString)
    } catch (e: Exception) {
```

### 7.3 数据迁移策略

#### A. 数据库版本升级迁移

当备份文件的数据库版本低于当前版本时，执行迁移：

**示例：从 v5 迁移到 v6**

```kotlin
/**
 * 数据迁移管理器
 */
class BackupDataMigrator {
    
    /**
     * 执行数据迁移
     */
    suspend fun migrate(
        backupData: BackupData,
        fromVersion: Int,
        toVersion: Int
    ): BackupData {
        var data = backupData
        
        // 依次执行中间版本的迁移
        for (version in fromVersion until toVersion) {
            data = when (version) {
                5 -> migrateFrom5To6(data)
                6 -> migrateFrom6To7(data)
                else -> data
            }
        }
        
        return data
    }
    
    /**
     * 从 v5 迁移到 v6
     * 变更：添加 WidgetConfigEntity 表
     */
    private fun migrateFrom5To6(data: BackupData): BackupData {
        // v6 新增了 Widget 配置表，但不影响其他数据
        // 备份中没有 widget_config.json，恢复时使用默认值即可
        return data
    }
    
    /**
     * 从 v6 迁移到 v7（假设未来变更）
     * 变更：SettingsEntity 新增字段 enableAutoBackup
     */
    private fun migrateFrom6To7(data: BackupData): BackupData {
        // 为旧版本数据添加默认值
        val settings = data.settings?.copy(
            enableAutoBackup = false // 默认值
        )
        return data.copy(settings = settings)
    }
}
```

**场景 1：新增字段**

- **示例**: 新增 `enableAutoBackup` 字段，默认为 `false`

**场景 2：删除字段**
- **策略**: 忽略备份中的该字段

**场景 3：字段重命名**

### 7.4 不兼容版本处理

当备份格式版本不兼容时：

```kotlin
fun validateBackupCompatibility(
    backupMetadata: BackupMetadata
): ValidationResult {
    val backupFormatVersion = SemVer.parse(backupMetadata.version)
    val currentFormatVersion = SemVer.parse(CURRENT_BACKUP_FORMAT_VERSION)
    
    return when {
        // 主版本号不同：不兼容
        backupFormatVersion.major != currentFormatVersion.major -> {
            ValidationResult.Incompatible(
                message = "备份文件版本 ${backupMetadata.version} 与当前版本 $CURRENT_BACKUP_FORMAT_VERSION 不兼容",
                suggestedAction = "请使用对应版本的应用恢复此备份"
            )
        }
        
        // 次版本号更高：警告（备份文件来自更新版本的应用）
        backupFormatVersion.minor > currentFormatVersion.minor -> {
            ValidationResult.Warning(
                message = "备份文件来自更新版本的应用，部分功能可能无法恢复"
            )
        }
        
        // 次版本号更低或相同：兼容
        else -> {
            ValidationResult.Compatible
        }
    }
}

sealed class ValidationResult {
    object Compatible : ValidationResult()
    data class Warning(val message: String) : ValidationResult()
    data class Incompatible(
        val message: String,
        val suggestedAction: String
    ) : ValidationResult()
}
```

### 7.5 向前兼容性保障

为了支持未来版本的向前兼容，备份文件应遵循以下原则：

## 9. 安全性考虑

### 9.1 敏感数据保护

#### A. 登录凭据加密

**加密算法**: AES-256-GCM（认证加密）

**密钥派生**: PBKDF2-HMAC-SHA256
- 迭代次数: 100,000
- 盐值长度: 32 字节（随机生成）
- 输出密钥长度: 256 位

**实现示例**:
```kotlin
object CredentialsEncryptor {
    private const val ALGORITHM = "AES/GCM/NoPadding"
    private const val KEY_LENGTH = 256
    private const val ITERATIONS = 100_000
    private const val SALT_LENGTH = 32
    private const val IV_LENGTH = 12
    
    fun encrypt(
        credentials: CredentialsData,
        password: String
    ): EncryptedCredentials {
        // 1. 生成随机盐值
        val salt = ByteArray(SALT_LENGTH)
        SecureRandom().nextBytes(salt)
        
        // 2. 派生密钥
        val keySpec = PBEKeySpec(
            password.toCharArray(),
            salt,
            ITERATIONS,
            KEY_LENGTH
        )
        val keyFactory = SecretKeyFactory.getInstance("PBKDF2WithHmacSHA256")
        val key = SecretKeySpec(
            keyFactory.generateSecret(keySpec).encoded,
            "AES"
        )
        
        // 3. 加密
        val cipher = Cipher.getInstance(ALGORITHM)
        cipher.init(Cipher.ENCRYPT_MODE, key)
        val iv = cipher.iv
        val plaintext = Json.encodeToString(credentials).toByteArray()
        val ciphertext = cipher.doFinal(plaintext)
        
        // 4. 返回加密数据
        return EncryptedCredentials(
            algorithm = ALGORITHM,
            salt = salt.toBase64(),
            iv = iv.toBase64(),
            ciphertext = ciphertext.toBase64()
        )
    }
    
    fun decrypt(
        encrypted: EncryptedCredentials,
        password: String
    ): CredentialsData {
        // 1. 派生密钥（使用相同盐值和参数）
        val salt = encrypted.salt.fromBase64()
        val keySpec = PBEKeySpec(
            password.toCharArray(),
            salt,
            ITERATIONS,
            KEY_LENGTH
        )
        val keyFactory = SecretKeyFactory.getInstance("PBKDF2WithHmacSHA256")
        val key = SecretKeySpec(
            keyFactory.generateSecret(keySpec).encoded,
            "AES"
        )
        
        // 2. 解密
        val cipher = Cipher.getInstance(ALGORITHM)
        val iv = encrypted.iv.fromBase64()
        val ciphertext = encrypted.ciphertext.fromBase64()
        cipher.init(
            Cipher.DECRYPT_MODE,
            key,
            GCMParameterSpec(128, iv)
        )
        
        try {
            val plaintext = cipher.doFinal(ciphertext)
            return Json.decodeFromString(plaintext.decodeToString())
        } catch (e: Exception) {
            throw DecryptionException("解密失败，密码可能错误")
        }
    }
}
```

### 9.2 数据完整性保证

#### A. SHA-256 校验和

**单文件校验**:
```kotlin
fun calculateFileChecksum(file: File): String {
    val digest = MessageDigest.getInstance("SHA-256")
    file.inputStream().use { input ->
        val buffer = ByteArray(8192)
        var bytesRead: Int
        while (input.read(buffer).also { bytesRead = it } != -1) {
            digest.update(buffer, 0, bytesRead)
        }
    }
    return digest.digest().toHexString()
}
```

**整体校验**:
```kotlin
fun verifyBackupIntegrity(
    backupDir: File,
    metadata: BackupMetadata
): Boolean {
    val checksums = Json.decodeFromString<Map<String, String>>(
        File(backupDir, "checksums.json").readText()
    )
    
    // 1. 验证各文件校验和
    for ((fileName, expectedChecksum) in checksums) {
        val file = File(backupDir, fileName)
        if (!file.exists()) {
            return false
        }
        val actualChecksum = calculateFileChecksum(file)
        if (actualChecksum != expectedChecksum) {
            return false
        }
    }
    
    // 2. 验证整体校验和
    val overallChecksum = calculateOverallChecksum(checksums)
    if (overallChecksum != metadata.checksum) {
        return false
    }
    
    return true
}
```

### 11.3 常见问题 (FAQ)

**Q1: 备份文件可以跨平台恢复吗？**
A: 可以。备份文件使用 JSON 格式，与平台无关。但需要注意路径格式的差异（如 Android 的 SAF URI）。

**Q2: 备份文件可以在不同版本的应用之间恢复吗？**
A: 可以。系统会自动检测版本兼容性并执行数据迁移。但主版本号不同的备份文件不兼容。

**Q3: 如果忘记了加密密码怎么办？**
A: 无法恢复。AES-256 加密是不可逆的，没有密码无法解密。建议用户妥善保管密码。

**Q4: 备份文件可以在云盘上同步吗？**
A: 可以。备份文件是普通的 ZIP 文件，可以手动上传到云盘或使用云盘同步功能。

**Q5: 恢复备份会删除当前数据吗？**
A: 根据冲突解决策略而定。默认情况下，大部分模块采用"合并"策略，不会删除现有数据。建议在恢复前先备份当前数据。
