# 深度链接（Deep Link）功能指南

## 概述

ProjectU 支持从外部点击 Pixiv 链接后直接跳转到 App 内对应的页面，无需手动搜索或导航。

## 支持的链接格式

### 用户页面

**新版格式：**
```
https://www.pixiv.net/users/{userId}
https://www.pixiv.net/en/users/{userId}
https://pixiv.net/users/{userId}
```

**旧版格式：**
```
http://www.pixiv.net/member.php?id={userId}
http://www.pixiv.net/u/{userId}
```

**示例：**
- `https://www.pixiv.net/users/4966721`
- `https://www.pixiv.net/en/users/4966721`
- `http://www.pixiv.net/member.php?id=11`
- `http://www.pixiv.net/u/11`

### 插画/漫画/动图详情

**新版格式：**
```
https://www.pixiv.net/artworks/{artworkId}
https://www.pixiv.net/en/artworks/{artworkId}
https://pixiv.net/artworks/{artworkId}
```

**旧版格式：**
```
http://www.pixiv.net/i/{artworkId}
http://www.pixiv.net/member_illust.php?illust_id={artworkId}
```

**示例：**
- `https://www.pixiv.net/artworks/101020338`
- `https://www.pixiv.net/en/artworks/101020338`
- `http://www.pixiv.net/i/18557054`
- `http://www.pixiv.net/member_illust.php?illust_id=18557054`

### 小说详情

**新版格式：**
```
https://www.pixiv.net/novel/show.php?id={novelId}
```

**旧版格式：**
```
http://www.pixiv.net/n/{novelId}
```

**示例：**
- `https://www.pixiv.net/novel/show.php?id=26587667`
- `http://www.pixiv.net/n/18557054`

### 小说系列

```
https://www.pixiv.net/novel/series/{seriesId}
```

**示例：**
- `https://www.pixiv.net/novel/series/11604214`

### 漫画系列

```
https://www.pixiv.net/user/{userId}/series/{seriesId}
```

**示例：**
- `https://www.pixiv.net/user/3414789/series/313864`

### Pixivision 特辑

```
https://www.pixivision.net/{lang}/a/{articleId}
```

**支持的语言：**
- `zh` - 简体中文
- `zh-tw` - 繁体中文
- `en` - English
- `ko` - 한국어
- `ja` - 日本語
- `th` - ไทย
- `ms` - Melayu

**示例：**
- `https://www.pixivision.net/zh/a/11289`
- `https://www.pixivision.net/zh-tw/a/11289`
- `https://www.pixivision.net/en/a/11289`
- `https://www.pixivision.net/ko/a/11289`
- `https://www.pixivision.net/ja/a/11289`

## 技术实现

### 架构

```
外部链接 → Android Intent → MainActivity → App Composable → DeepLinkHandler → Screen
```

### 核心组件

1. **`DeepLinkParser`** (`ui/navigation/DeepLinkParser.kt`)
   - 解析各种 Pixiv URL 格式
   - 返回 `DeepLinkTarget` sealed class

2. **`DeepLinkHandler`** (`ui/navigation/DeepLinkHandler.kt`)
   - 将 `DeepLinkTarget` 转换为对应的 Screen
   - 执行 Voyager Navigator 导航

3. **`AndroidManifest.xml`**
   - 配置 `intent-filter` 拦截 pixiv.net 域名链接
   - 使用 `android:launchMode="singleTask"` 确保单实例

4. **`MainActivity.kt`**
   - 处理 `onCreate` 和 `onNewIntent` 中的 Intent
   - 将深度链接 URL 传递给 `App` Composable

5. **`App.kt`**
   - 接收 `deepLink` 参数
   - 在 Navigator 内使用 `LaunchedEffect` 处理导航

### 状态流程

```kotlin
// 1. Intent 接收
override fun onCreate(savedInstanceState: Bundle?) {
    handleIntent(intent)
}

override fun onNewIntent(intent: Intent) {
    handleIntent(intent)
}

// 2. 解析并存储
private fun handleIntent(intent: Intent?) {
    if (intent?.action == Intent.ACTION_VIEW) {
        pendingDeepLink.value = intent.data?.toString()
    }
}

// 3. 传递给 Compose
App(
    deepLink = pendingDeepLink.value,
    onDeepLinkConsumed = { pendingDeepLink.value = null }
)

// 4. 处理导航
LaunchedEffect(deepLink) {
    if (deepLink != null && isLoggedIn) {
        DeepLinkHandler.handleUrl(deepLink, navigator)
        onDeepLinkConsumed()
    }
}
```

4. App 打开并跳转到对应页面

## 注意事项

1. **登录状态**：深度链接仅在用户已登录时生效，未登录时会显示登录页面
2. **单实例模式**：使用 `singleTask` 启动模式，新链接不会创建新的 Activity
3. **App Links 验证**：`android:autoVerify="true"` 需要服务端配置 Digital Asset Links（可选）
4. **HTTP 重定向**：同时支持 http 和 https 链接
5. **多语言路径**：支持 `/en/` 等语言前缀的 URL

## 扩展

如需支持新的链接格式，修改以下文件：

1. `DeepLinkParser.kt` - 添加新的正则表达式和解析逻辑
2. `DeepLinkTarget.kt` - 添加新的 sealed class 子类
3. `DeepLinkHandler.kt` - 添加目标到 Screen 的映射
4. `AndroidManifest.xml` - 添加新的 `pathPattern`
