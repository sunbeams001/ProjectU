
# 设置系统架构

> 🏗️ 项目架构: [../project/项目架构参考文档.md](../project/项目架构参考文档.md)

## 1. 架构分层

- **UI 层**：Compose 多平台，`SettingsScreen` 通过 `SettingsViewModel` 响应式展示和修改设置。
- **ViewModel 层**：`SettingsViewModel` 持有 `StateFlow<AppSettings>`，提供更新方法。
- **Domain 层**：`SettingsRepository` 接口，定义设置相关操作。
- **数据层**：
  - `SettingsRepositoryImpl` 实现仓储接口，委托 `SettingsStore`。
  - `SettingsStore` 基于 Room 数据库（`SettingsDao`/`SettingsEntity`）持久化设置。

## 2. 数据流与持久化

- 读取：UI 订阅 `settingsState`，底层通过 Flow 监听数据库，自动推送最新设置。
- 修改：UI 调用 ViewModel 的更新方法，依次传递到 Repository → Store → Dao，最终写入数据库并自动流式更新。
- 支持完整重置（resetSettings）、批量更新（updateSettings）。

## 3. 多语言与主题

- `AppLanguage`/`PixivLanguage`/`ThemeMode` 枚举，含 code/displayName 字段。
- `LocaleManager` 通过 `SettingsRepository` 管理语言，支持运行时切换和持久化。
- 主题切换通过 `ThemeMode`，UI 响应式适配。

## 4. Pixiv 语言同步

- `SyncPixivLanguageUseCase` 监听设置变化，自动同步到 `PixivConfigStore`，保证 Pixiv API 请求语言一致。

## 5. 依赖注入（Koin）

- `databaseModule`：提供 Room 数据库、Dao、SettingsStore。
- `repositoryModule`：提供 SettingsRepositoryImpl。
- `viewModelModule`：提供 SettingsViewModel。
- 依赖关系清晰，支持多平台（Android/Desktop）。

## 6. 扩展性

- 新增设置项：扩展 AppSettings、SettingsEntity、Dao、UI 即可。
- 支持切换持久化方案（如 DataStore）。
- 领域/数据/界面分层，便于单元测试和 Mock。

## 7. 跨平台支持

- 共享核心逻辑（commonMain），Android/Desktop 仅做平台集成和依赖注入。

## 8. 主要类关系（简表）

- `AppSettings`：数据模型，含 appLanguage、pixivLanguage、themeMode。
- `SettingsStore`：持久化，基于 Room，操作 SettingsDao。
- `SettingsRepository`/`Impl`：仓储接口与实现。
- `SettingsViewModel`：状态管理，供 UI 订阅。
- `SettingsScreen`：UI 展示与交互。

---

## 📌 核心优点

✅ **分层清晰**: Domain - Data - Presentation 三层分离  
✅ **响应式更新**: 基于 Flow 的自动状态同步  
✅ **可扩展**: 易于添加新设置项  
✅ **跨平台**: Android + Desktop 共享核心逻辑  
✅ **类型安全**: 使用 sealed class 和 enum
