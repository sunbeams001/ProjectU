================================================================================
                            快速使用示例
================================================================================

// 1. 配置 Koin（应用启动时）
startKoin {
    modules(
        pixivApiModule("你的PHPSESSID"),
        repositoryModule
    )
}

// 2. 在 ViewModel 中使用
class HomeViewModel : ViewModel(), KoinComponent {
    private val repository: ArtworkRepository by inject()
    
    fun loadArtworks() = viewModelScope.launch {
        // 获取推荐
        repository.getRecommendedArtworks(1, 20)
            .onSuccess { artworks ->
                // 显示作品
            }
    }
}

================================================================================
                            重要提示
================================================================================

⚠️  不要硬编码 PHPSESSID
    - 使用 EncryptedSharedPreferences (Android)
    - 使用环境变量或加密配置 (Desktop)

⚠️  图片加载需要设置 Referer
    - 在 ImageRequest 中添加 Referer header
    - 参考文档中的示例代码

⚠️  注意 API 调用频率
    - 避免过于频繁的请求
    - 建议添加请求间隔
    - 使用缓存减少重复请求
