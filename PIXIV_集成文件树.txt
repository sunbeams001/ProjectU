================================================================================
                            目录结构说明
================================================================================

📁 data/local/
   配置管理相关类
   - PixivConfig: 配置数据类
   - PixivConfigStore: 配置存储管理

📁 data/remote/api/
   Pixiv API 客户端和各API模块
   - PixivApiClient: 核心HTTP客户端，处理认证和请求
   - PixivApi: API门面，统一访问入口
   - IllustApi: 插画相关API（9个方法）
   - UserApi: 用户相关API（7个方法）
   - BookmarkApi: 收藏相关API（6个方法）
   - RankingApi: 排行榜相关API（8个方法）

📁 data/remote/dto/pixiv/
   Pixiv API 数据传输对象
   - PixivResponse: 响应基类
   - IllustDto: 插画相关DTO（15个类）
   - UserDto: 用户相关DTO（8个类）
   - RankingDto: 排行榜相关DTO（3个类）

📁 data/remote/mapper/
   DTO到Domain模型的映射器
   - PixivArtworkMapper: IllustDto → Artwork 转换

📁 data/repository/
   Repository 接口的具体实现
   - ArtworkRepositoryImpl: 作品仓储实现
   - UserRepositoryImpl: 用户仓储实现

📁 examples/
   代码使用示例
   - PixivApiUsageExample: 10个完整示例

================================================================================
                            API 方法清单
================================================================================

📌 IllustApi (插画API) - 9个方法
   1. getDetail(pid)                     获取作品详情
   2. getBookmarkData(pid)               获取收藏状态
   3. getUgoiraMeta(pid)                 获取动图元数据
   4. search(keyword, ...)               搜索作品
   5. getDiscovery(...)                  发现作品
   6. getFollowLatest(...)               关注最新
   7. getRecommendInit(...)              推荐初始化
   8. getRecommendIllusts(...)           批量推荐
   9. postLike(pid)                      点赞作品

📌 UserApi (用户API) - 7个方法
   1. getUserInfo(uid)                   获取用户信息
   2. getProfileAll(uid)                 获取作品概况
   3. getProfileIllusts(...)             获取用户插画
   4. getUserBookmarkIllusts(...)        获取用户收藏
   5. getRecommendUsers(...)             推荐用户
   6. followUser(...)                    关注用户
   7. unfollowUser(uid)                  取消关注

📌 BookmarkApi (收藏API) - 6个方法
   1. addIllust(...)                     收藏插画
   2. deleteIllust(bookmarkId)           删除收藏
   3. deleteIllusts(ids)                 批量删除收藏
   4. addNovel(...)                      收藏小说
   5. deleteNovel(bookId)                删除小说收藏
   6. deleteNovels(ids)                  批量删除小说收藏

📌 RankingApi (排行榜API) - 8个方法
   1. getIllustRanking(...)              通用排行榜
   2. getDailyRanking(...)               日榜
   3. getWeeklyRanking(...)              周榜
   4. getMonthlyRanking(...)             月榜
   5. getRookieRanking(...)              新人榜
   6. getOriginalRanking(...)            原创榜
   7. getMaleRanking(...)                男性向榜
   8. getFemaleRanking(...)              女性向榜
