## 数据流向

### 1. 读取设置流程

```
用户打开设置页面
      ↓
SettingsScreen 初始化
      ↓
SettingsViewModel 注入
      ↓
settingsState.collectAsState()
      ↓
SettingsRepository.getSettings()
      ↓
SettingsStore.settings (Flow)
      ↓
返回 AppSettings 数据
      ↓
UI 显示当前设置
```

### 2. 修改设置流程

```
用户点击设置项
      ↓
显示选择对话框
      ↓
用户选择新值
      ↓
ViewModel.updateXXX()
      ↓
SettingsRepository.updateXXX()
      ↓
SettingsStore.setXXX()
      ↓
更新 MutableStateFlow
      ↓
Flow 发出新值
      ↓
ViewModel.settingsState 更新
      ↓
UI 自动重组显示新值
```

### 3. Pixiv 语言同步流程

```
用户修改 Pixiv 语言
      ↓
ViewModel.updatePixivLanguage()
      ↓
SettingsRepository.updatePixivLanguage()
      ↓
SettingsStore.setPixivLanguage()
      ↓
更新 AppSettings.pixivLanguage
      ↓
SyncPixivLanguageUseCase 监听到变化
      ↓
PixivConfigStore.syncLanguageFromSettings()
      ↓
更新 PixivConfig.language
      ↓
后续 Pixiv API 调用使用新语言
```

## 扩展点

系统设计了多个扩展点，便于后续功能添加：

```
1. 数据模型扩展
   AppSettings + 新字段
   
2. 存储层扩展
   SettingsStore + 新方法
   
3. 仓储层扩展
   SettingsRepository + 新接口
   SettingsRepositoryImpl + 新实现
   
4. UI 扩展
   SettingsScreen + 新设置项
   + 新对话框组件
   
5. 持久化扩展
   SettingsStore → DataStore
   SettingsStore → SQLite
```

## 总结

该设置系统具有以下优点：

✅ **分层清晰**: UI、Domain、Data 三层分离  
✅ **响应式**: 使用 Flow 实现数据流  
✅ **可测试**: 接口驱动，易于 Mock  
✅ **可扩展**: 添加新设置项非常简单  
✅ **跨平台**: Android 和 Desktop 代码共享  
✅ **类型安全**: 使用枚举避免魔法字符串
