# 设置功能快速开始 🚀

## 5 分钟快速上手

### 1️⃣ 访问设置页面（用户视角）

1. 运行应用（Android 或 Desktop）
2. 点击底部导航栏的"我的"标签
3. 点击"设置"按钮
4. 进入设置页面

### 2️⃣ 修改语言设置

**应用语言：**
1. 点击"应用语言"
2. 在对话框中选择目标语言
3. 设置立即生效（需重启应用以完全切换界面语言）

**Pixiv 语言：**
1. 点击"Pixiv 语言偏好"
2. 在对话框中选择目标语言
3. 设置立即生效，影响后续 Pixiv API 数据获取

### 3️⃣ 在代码中使用设置（开发者视角）

#### 方式一：在 Composable 中使用

```kotlin
import com.projectu.ui.screens.settings.SettingsViewModel
import org.koin.compose.koinInject

@Composable
fun MyScreen() {
    // 注入 ViewModel
    val viewModel: SettingsViewModel = koinInject()
    
    // 收集设置状态
    val settings by viewModel.settingsState.collectAsState()
    
    // 使用设置
    Text("当前语言: ${settings.appLanguage.displayName}")
    Text("Pixiv 语言: ${settings.pixivLanguage.displayName}")
    
    // 修改设置
    Button(onClick = { 
        viewModel.updateAppLanguage(AppLanguage.ENGLISH) 
    }) {
        Text("切换到英文")
    }
}
```

#### 方式二：在 ViewModel 中使用

```kotlin
import com.projectu.shared.domain.repository.SettingsRepository
import org.koin.core.component.inject

class MyViewModel : ViewModel(), KoinComponent {
    private val settingsRepository: SettingsRepository by inject()
    
    init {
        viewModelScope.launch {
            // 获取当前设置
            val settings = settingsRepository.getCurrentSettings()
            println("当前应用语言: ${settings.appLanguage}")
            
            // 监听设置变化
            settingsRepository.getSettings().collect { settings ->
                println("设置已更新: $settings")
            }
        }
    }
    
    fun changeLanguage() {
        viewModelScope.launch {
            settingsRepository.updateAppLanguage(AppLanguage.JAPANESE)
        }
    }
}
```

### 4️⃣ 添加新的设置项

假设要添加"下载质量"设置，只需 6 步：

#### 步骤 1: 定义枚举
```kotlin
// 在 AppSettings.kt 中
enum class DownloadQuality {
    ORIGINAL,  // 原图
    LARGE,     // 大图
    MEDIUM     // 中图
}
```

#### 步骤 2: 更新数据模型
```kotlin
// 在 AppSettings.kt 中
data class AppSettings(
    val appLanguage: AppLanguage,
    val pixivLanguage: PixivLanguage,
    val themeMode: ThemeMode,
    val downloadQuality: DownloadQuality = DownloadQuality.ORIGINAL  // 新增
)
```

#### 步骤 3: 更新 Store
```kotlin
// 在 SettingsStore.kt 中
fun setDownloadQuality(quality: DownloadQuality) {
    _settings.value = _settings.value.copy(downloadQuality = quality)
}
```

#### 步骤 4: 更新 Repository
```kotlin
// 在 SettingsRepository.kt 中
interface SettingsRepository {
    // ...
    suspend fun updateDownloadQuality(quality: DownloadQuality)
}

// 在 SettingsRepositoryImpl.kt 中
override suspend fun updateDownloadQuality(quality: DownloadQuality) {
    settingsStore.setDownloadQuality(quality)
}
```

#### 步骤 5: 更新 ViewModel
```kotlin
// 在 SettingsViewModel.kt 中
fun updateDownloadQuality(quality: DownloadQuality) {
    viewModelScope.launch {
        settingsRepository.updateDownloadQuality(quality)
    }
}
```

#### 步骤 6: 更新 UI
```kotlin
// 在 SettingsScreen.kt 中
item {
    SettingsItem(
        title = "下载质量",

```

## 常见场景示例

### 场景 1: 根据语言设置显示不同内容

```kotlin
@Composable
fun WelcomeScreen() {
    val viewModel: SettingsViewModel = koinInject()
    val settings by viewModel.settingsState.collectAsState()
    
    val welcomeMessage = when (settings.appLanguage) {
        AppLanguage.SIMPLIFIED_CHINESE -> "欢迎使用 ProjectU"
        AppLanguage.TRADITIONAL_CHINESE -> "歡迎使用 ProjectU"
        AppLanguage.ENGLISH -> "Welcome to ProjectU"
        AppLanguage.JAPANESE -> "ProjectU へようこそ"
        AppLanguage.KOREAN -> "ProjectU에 오신 것을 환영합니다"
    }
    
    Text(welcomeMessage)
}
```

### 场景 2: 在网络请求中使用 Pixiv 语言设置

```kotlin
class ArtworkRepository(
    private val settingsRepository: SettingsRepository,
    private val pixivApi: PixivApi
) {
    suspend fun getArtwork(id: Long): Artwork {
        val settings = settingsRepository.getCurrentSettings()
        
        // Pixiv API 会根据语言设置返回对应语言的数据
        return pixivApi.getArtwork(
            id = id,
            language = settings.pixivLanguage.code
        )
    }
}
```

### 场景 3: 监听设置变化并做出响应

```kotlin
@Composable
fun LanguageAwareScreen() {
    val viewModel: SettingsViewModel = koinInject()
    val settings by viewModel.settingsState.collectAsState()
    
    // 当语言变化时执行某些操作
    LaunchedEffect(settings.appLanguage) {
        // 重新加载数据、更新 UI 等
        println("语言已切换到: ${settings.appLanguage.displayName}")
    }
    
    // UI 内容...
}
```

### 场景 4: 设置默认值

```kotlin
class MyViewModel : ViewModel() {
    init {
        // 首次启动时设置默认值
        viewModelScope.launch {
            val settings = settingsRepository.getCurrentSettings()
            if (settings == AppSettings.DEFAULT) {
                // 根据系统语言设置默认应用语言

                settingsRepository.updateAppLanguage(systemLanguage)
            }
        }
    }
}
```

## 可用的 API

### SettingsViewModel

| 方法 | 说明 |
|------|------|
| `settingsState: StateFlow<AppSettings>` | 设置状态流 |
| `updateAppLanguage(language: AppLanguage)` | 更新应用语言 |
| `updatePixivLanguage(language: PixivLanguage)` | 更新 Pixiv 语言 |
| `updateThemeMode(mode: ThemeMode)` | 更新主题模式 |
| `resetSettings()` | 重置为默认设置 |

### SettingsRepository

| 方法 | 说明 |
|------|------|
| `getSettings(): Flow<AppSettings>` | 获取设置流 |
| `getCurrentSettings(): AppSettings` | 获取当前设置（挂起函数） |
| `updateAppLanguage(language: AppLanguage)` | 更新应用语言 |
| `updatePixivLanguage(language: PixivLanguage)` | 更新 Pixiv 语言 |
| `updateThemeMode(mode: ThemeMode)` | 更新主题模式 |
| `updateSettings(settings: AppSettings)` | 批量更新设置 |
| `resetSettings()` | 重置设置 |

### AppSettings

| 属性 | 类型 | 说明 |
|------|------|------|
| `appLanguage` | `AppLanguage` | 应用界面语言 |
| `pixivLanguage` | `PixivLanguage` | Pixiv 数据语言 |
| `themeMode` | `ThemeMode` | 主题模式 |

### 枚举值

**AppLanguage:**
- `SIMPLIFIED_CHINESE` - 简体中文
- `TRADITIONAL_CHINESE` - 繁体中文
- `ENGLISH` - 英文
- `JAPANESE` - 日文
- `KOREAN` - 韩文

**PixivLanguage:**
- `SIMPLIFIED_CHINESE` - 简体中文
- `TRADITIONAL_CHINESE` - 繁体中文
- `ENGLISH` - 英文
- `JAPANESE` - 日文
- `KOREAN` - 韩文

**ThemeMode:**
- `LIGHT` - 浅色主题
- `DARK` - 深色主题
- `SYSTEM` - 跟随系统

## 最佳实践

### ✅ 推荐做法

1. **使用 ViewModel 收集状态**
   ```kotlin
   val settings by viewModel.settingsState.collectAsState()
   ```

2. **在后台线程读取设置**
   ```kotlin
   viewModelScope.launch {
       val settings = repository.getCurrentSettings()
   }
   ```

3. **监听设置变化**
   ```kotlin
   LaunchedEffect(Unit) {
       settingsRepository.getSettings().collect { settings ->
           // 响应变化
       }
   }
   ```

### ❌ 避免的做法

1. **不要在主线程调用挂起函数**
   ```kotlin
   // ❌ 错误
   val settings = settingsRepository.getCurrentSettings()
   
   // ✅ 正确
   viewModelScope.launch {
       val settings = settingsRepository.getCurrentSettings()
   }
   ```

2. **不要直接修改 AppSettings**
   ```kotlin
   // ❌ 错误
   val settings = AppSettings(appLanguage = AppLanguage.ENGLISH)
   
   // ✅ 正确
   viewModel.updateAppLanguage(AppLanguage.ENGLISH)
   ```

3. **不要跳过 Repository 层**
   ```kotlin
   // ❌ 错误
   val store: SettingsStore = get()
   store.setAppLanguage(AppLanguage.ENGLISH)
   
   // ✅ 正确
   val repository: SettingsRepository = get()
   repository.updateAppLanguage(AppLanguage.ENGLISH)
   ```

## 故障排查

### 问题：设置修改后没有生效

**可能原因：**
1. 没有使用 `collectAsState()` 收集状态
2. ViewModel 没有正确注入

**解决方案：**
```kotlin
// 确保使用 collectAsState
val settings by viewModel.settingsState.collectAsState()

// 确保 ViewModel 正确注入
val viewModel: SettingsViewModel = koinInject()
```

### 问题：应用重启后设置丢失

**原因：** 当前使用内存存储，应用重启会丢失数据

**解决方案：** 待实现持久化存储（DataStore 或 SQLite）

### 问题：Pixiv 语言没有同步到 API

**可能原因：** PixivConfigStore 没有正确同步

**解决方案：**
```kotlin
// 手动同步
val syncUseCase: SyncPixivLanguageUseCase = koinInject()
syncUseCase.syncNow()
```
